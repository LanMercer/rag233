> 数据结构/算法小抄（周内新增名词，初次出现即解释）：
> - **动态规划（DP, Dynamic Programming）** = 把大问题拆成**结构相同的子问题**、**每个子问题只算一次**、按顺序把答案"递推"出大问题答案。三要素：**状态定义 + 转移方程 + 边界**。它跟"递归 + 记忆化"是同一件事的两个方向（自顶向下 / 自底向上）。
> - **重复子问题（Overlapping Subproblems）** = 同一个子问题在递归树里被反复求值（斐波那契 `F(3)` 被算无数次）——**这是 DP 存在的唯一理由**。
> - **最优子结构（Optimal Substructure）** = 大问题的最优解能由子问题的最优解拼出来（打家劫舍、最大子数组和都靠这个）。
> - **滚动变量（Rolling Variables）** = 递推时只留"下一轮还要用到的几个旧状态"，把 O(n) 状态数组压成 O(1)——"用空间换时间"的反向操作："用更少空间做同样的事"。
> - **Kadane 算法** = 力扣 53 的 O(n)/O(1) 一维 DP 解法：`dp[i] = max(nums[i], dp[i-1]+nums[i])`，一句话是"接上前面 or 自己重开"。
> - **完全背包（Unbounded Knapsack）** = 每种物品可取**无限件**的背包问题；零钱兑换（322）是它的最简形态（求"最少件数"而非"最大价值"）。
> - **全幺模矩阵（Totally Unimodular）** = 一个整数矩阵的所有子方阵行列式都是 ±1；**若约束矩阵全幺模，则 LP 松弛的最优解自动是整数解**——这是"为什么打家劫舍有贪心/DP 多项式解法"的理论解释。

## 专题一：一维 DP 的"地基"——重复子问题与三种写法（509、70）

### 1. 509. 斐波那契数 —— 简单 ✅（9/18 · Day16 完成）｜ 必做，DP 专题地基

**考点**：递归 / 记忆化 / 递推三写法对照，看清"重复子问题"

**题目**：`F(0)=0, F(1)=1, F(n)=F(n-1)+F(n-2)`，给定 `n`（0 ≤ n ≤ 30），求 `F(n)`。

**思路**：定义直译就是递归，但朴素递归把 `F(3)` 算了上百万次（n=30）；**"同一件事只算一次"就是动态规划的全部意义**。

| 写法 | 思路 | 复杂度 | 一句话点评 |
|---|---|---|---|
| ① 朴素递归 | 直接把定义翻成代码 | 时间 O(2ⁿ)、空间 O(n) 栈 | 定义最直白，但**重复计算爆炸** |
| ② 记忆化递归（自顶向下） | 递归 + 一个 `memo` 表，算过就存 | 时间 O(n)、空间 O(n) | **不改变思路，只加缓存**——"用空间换时间"的最小示范 |
| ③ 递推/滚动变量（自底向上） | 从小到大算，只留前两个值 | 时间 O(n)、**空间 O(1)** | 最优；DP 的"标准姿势" |

**代码**：

```python
class Solution:
    # ① 朴素递归：定义直译，但重复子问题导致指数复杂度
    def fib_recursive(self, n: int) -> int:
        if n < 2:
            return n
        return self.fib_recursive(n - 1) + self.fib_recursive(n - 2)

    # ② 记忆化：递归 + 缓存（同一个 n 只算一次）
    def fib_memo(self, n: int) -> int:
        memo = {}
        def dfs(k: int) -> int:
            if k < 2:
                return k
            if k in memo:          # 算过就直接取
                return memo[k]
            memo[k] = dfs(k - 1) + dfs(k - 2)
            return memo[k]
        return dfs(n)

    # ③ 递推 + 滚动变量：只留前两个（空间 O(1)），本题最优
    def fib(self, n: int) -> int:
        if n < 2:
            return n
        a, b = 0, 1                 # a=F(0), b=F(1)
        for _ in range(2, n + 1):
            a, b = b, a + b         # 滚动：(F(k-2), F(k-1)) → (F(k-1), F(k))
        return b
```

**复杂度**：③ 时间 O(n)、空间 O(1)（② 空间 O(n)）；朴素递归 O(2ⁿ)。

**数学视角（面试加分讲法）**：递推式 `F(n)=F(n-1)+F(n-2)` 是一个**线性二阶常系数递推**，通项就是 Binet 公式 `F(n) = (φⁿ − ψⁿ)/√5`（φ 是黄金比、ψ 是它的共轭）。

**这题为什么必须用 DP 而不能直接套公式**：浮点幂在 `n` 稍大时误差会放大（φⁿ 是**指数级增长**，double 只有 53 位有效位），所以工程上宁愿用 O(n) 的迭代。**"数学上闭式解存在 ≠ 数值上可用"**——这是能当场讲出深度的一句话。

而"记忆化 → 递推"的关系，用概率的语言说就是：**递归是沿条件展开，记忆化是让同一条件只被积分一次**（把指数级的重复求和压成线性的单次累加）。

### 2. 70. 爬楼梯 —— 简单 ✅（9/21 · Day17 完成）｜ 必做，一维 DP 模板题

**考点**："最后一步只有两种可能" → 递推；方案数（组合）视角

**题目**：每次可以爬 1 或 2 个台阶，问爬到第 `n` 阶共有多少种不同的走法（`1 ≤ n ≤ 45`）。

**思路**：最后一步只有两种可能——从第 `n-1` 阶走 1 步上来，或从第 `n-2` 阶走 2 步上来。所以

```
dp[n] = dp[n-1] + dp[n-2],   dp[1] = 1, dp[2] = 2
```

这个式子就是**斐波那契数列的平移**（`dp[n] = F(n+1)`）。509 已经把"重复子问题 → 记忆化 → 递推"讲透了，**今天这题的作用是：把同一套思路从"求数列项"迁移到"求方案数"**。

| 写法 | 复杂度 | 一句话 |
|---|---|---|
| ① 朴素递归 `f(n) = f(n-1) + f(n-2)` | 时间 O(2ⁿ) | 定义直译，但重复计算爆炸（n=45 就跑不动了） |
| ② 记忆化递归 | 时间 O(n)、空间 O(n) | 加一个 `memo`，算过就取 |
| ③ 递推 + 滚动变量 | 时间 O(n)、**空间 O(1)** | 最优；DP 的标准姿势 |

**代码**：

```python
class Solution:
    # ① 朴素递归（指数级，只用于讲清"重复子问题"，提交会超时）
    def climbStairs_recursive(self, n: int) -> int:
        if n <= 2:
            return n
        return self.climbStairs_recursive(n - 1) + self.climbStairs_recursive(n - 2)

    # ② 记忆化递归（自顶向下）
    def climbStairs_memo(self, n: int) -> int:
        memo = {1: 1, 2: 2}
        def dfs(k: int) -> int:
            if k in memo:
                return memo[k]
            memo[k] = dfs(k - 1) + dfs(k - 2)
            return memo[k]
        return dfs(n)

    # ③ 递推 + 滚动变量（自底向上，本题最优）
    def climbStairs(self, n: int) -> int:
        if n <= 2:
            return n
        a, b = 1, 2                 # a = dp[n-2], b = dp[n-1]
        for _ in range(3, n + 1):
            a, b = b, a + b         # 滚动：(dp(k-2), dp(k-1)) → (dp(k-1), dp(k))
        return b
```

**复杂度**：③ 时间 O(n)、空间 O(1)。

**数学视角（面试加分，能讲出深度）**：

1. **方案数的组合表达**：爬 `n` 阶若用了 `k` 次"两步"，则总步数里的位置组合数是 `C(n-k, k)`，于是
   `dp[n] = Σ_{k=0}^{⌊n/2⌋} C(n-k, k)`。
   验算：`n=4` → `C(4,0)+C(3,1)+C(2,2) = 1+3+1 = 5` ✅。
2. **递推与杨辉三角是同一个恒等式**：`C(n-k,k) = C((n-1)-k, k) + C((n-2)-(k-1), k-1)` —— 这正是帕斯卡恒等式 `C(m,r) = C(m-1,r) + C(m-1,r-1)`。**也就是说：`dp[i]=dp[i-1]+dp[i-2]` 不过是"二项式系数在杨辉三角上往下走"的另一种写法。**
3. **更快？用矩阵快速幂**：`[dp[n], dp[n-1]]ᵀ = M^(n-1)·[dp[1], dp[0]]ᵀ`，其中 `M = [[1,1],[1,0]]` → `O(log n)`。这解释了为什么这类递推的增长是**指数级**（特征值 φ、ψ，主导项 φⁿ，φ 是黄金比）。**但 n≤45 时 O(n) 已经够快，工程上不需要**——"能更快"和"该不该更快"是两件事。

> **做完**：提交通过后存入 GitHub `leetcode` 仓库（`动态规划` 分类），题解注释写"数学视角"（组合表达 / 帕斯卡恒等式 / 矩阵快速幂与指数增长）。

## 专题二：一维 DP 的"选/不选"模板（198、53、152）

> 这三题**共用同一个骨架**：**"最后一步只有有限种可能" → `dp[i] = opt( 延续 dp[i-1] , 跳跃 dp[i-2] )`**。区别只在 **合并算子**（`+` 计数 / `max` 求最优）和**要不要额外维护一个状态**。

### 3. 198. 打家劫舍 —— 中等 ✅（9/22 · Day18 完成，用户确认）｜ 必做，「选/不选」模板

**考点**：一维 DP 的"约束下求最优"；0-1 整数规划视角

**题**：一排房子，第 `i` 间有 `nums[i]` 元；**不能偷相邻两间**，求最多能偷多少。

**① 从"最后一步"想（和爬楼梯同一套骨架）**：偷到第 `i` 间时只有两种可能——

- **偷第 `i` 间** → 第 `i-1` 间**不能偷** → 收益 = `dp[i-2] + nums[i]`
- **不偷第 `i` 间** → 收益 = `dp[i-1]`

→ **状态转移方程**：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`

**② 三写法对照**：

```python
# ① 朴素递归：定义直译，指数级 → n=40 就卡死
def rob_rec(nums, i):
    if i < 0: return 0
    return max(rob_rec(nums, i - 1), rob_rec(nums, i - 2) + nums[i])

# ② 记忆化：O(n) 时间 / O(n) 空间
from functools import lru_cache
def rob_memo(nums):
    @lru_cache(maxsize=None)
    def f(i):
        if i < 0: return 0
        return max(f(i - 1), f(i - 2) + nums[i])
    return f(len(nums) - 1)

# ③ 递推 + 滚动变量：O(n) 时间 / O(1) 空间（本题最优）
def rob(nums):
    prev2, prev1 = 0, 0          # prev2 = dp[i-2], prev1 = dp[i-1]
    for x in nums:
        prev2, prev1 = prev1, max(prev1, prev2 + x)
    return prev1
```

**边界**：`n == 0` → 0；`n == 1` → `nums[0]`（滚动变量写法天然覆盖）。

**③ 数学视角（面试加分点）**：

- **与爬楼梯/斐波那契的关系**：三者骨架**完全同构**——都是「**最后一步只有有限种可能**」→ 递推。区别只在**合并算子**：爬楼梯是 `+`（方案数相加），打家劫舍是 `max`（收益取最优）。→ 这就是 DP 的通用模板：`dp[i] = opt( dp[i-1] 的延续 , dp[i-2] 的跳跃 )`。
- **它的本质是"带约束的 0-1 整数规划"**：
  \[
  \max \sum_i x_i \cdot nums_i \quad \text{s.t.} \quad x_i \in \{0,1\},\; x_i + x_{i+1} \le 1
  \]
  这个约束矩阵是**全幺模（totally unimodular）**的 → 它的 **LP 松弛最优解自动是整数解** → **贪心/DP 都能拿到最优**。这是"为什么这个问题有多项式解法"的理论解释，也是**这类题为什么常见**的原因。
- **DP 的复杂度账**：状态数 `O(n)` × 每状态转移 `O(1)` = `O(n)`；空间用滚动变量降到 `O(1)`。**"用空间换时间"在这里体现为**：朴素递归重复算子问题 `O(2^n)` → 记忆化把每个子问题算一次 `O(n)`。

**④ 一句话总结**：**DP = 用递推避免重复计算**；状态转移方程 = **"条件最优值的递推"**；`max` 版本对应"决策问题"，`+` 版本对应"计数问题"。

### 4. 53. 最大子数组和 —— 中等 ✅（9/22 · Day19 完成，用户确认）｜ 必做，DP vs 贪心

**考点**：Kadane 算法（DP）与贪心的等价性；前缀和视角

**题目**：给一个整数数组 `nums`，找**和最大**的连续子数组，返回其和。

**两种思路，都要会（面试常被要求"你还能用别的方法吗"）**：

```python
# ① DP（Kadane）：dp[i] = 以 i 结尾的最大子数组和
#    转移：dp[i] = max(nums[i], dp[i-1] + nums[i])
#    直觉：要么"自己重新开始"，要么"接着前面那串"——这就是"选 / 不选"的变体
def max_sub_array_dp(nums):
    best = cur = nums[0]
    for x in nums[1:]:
        cur = max(x, cur + x)     # 重新开始 or 延续
        best = max(best, cur)
    return best

# ② 贪心（本质与 DP 同构，但叙述是"累计和 <0 就清零"）
#    直觉：如果前面的累计和已经是负贡献，带着它只会拖累后面 → 直接扔掉
def max_sub_array_greedy(nums):
    best, cur = nums[0], 0
    for x in nums:
        cur += x
        best = max(best, cur)
        if cur < 0:
            cur = 0              # 负贡献，清零重来
    return best
```

**复杂度**：两者都是 **O(n) 时间 / O(1) 空间**；**DP 更"通用"**（能改造成求"最大子矩阵和"、带约束的版本），**贪心更"贴直觉"**（但清零的合法性需要一句话证明）。

**数学视角（写进题解注释）**：最大子数组和 = 对**前缀和**求"最大差值"（`max_{j>i} (P[j] − P[i])`）→ 一趟扫描里维护"目前为止最小的前缀和"即可。**这就是 DP 与贪心在这里等价的根本原因**：`dp[i-1] + nums[i] < nums[i]` 等价于"前面的累计和是负的"。

### 5. 152. 乘积最大子数组 —— 中等 🔄（9/22 · Day20 · 教程与代码已备好）｜ 与 53 同一族

**考点**：**多维护一个状态**（负数会翻转最值）——这是 53 的"陷阱版"

**题目**：给一个整数数组 `nums`，找**乘积最大**的连续子数组，返回其乘积。

**53 是加法、152 是乘法**，结构一样，但**多了一个陷阱**：

```python
# 思路：乘法里"最小"可能变"最大"（负数 × 负 = 正）
# → 同时维护 dp_max 和 dp_min（这是本题唯一的新东西）
def maxProduct(nums):
    dp_max = dp_min = ans = nums[0]
    for x in nums[1:]:
        # ⚠ 必须"同时"更新：用旧的 dp_max/dp_min 一起算
        cand = (dp_max * x, dp_min * x, x)
        dp_max, dp_min = max(cand), min(cand)
        ans = max(ans, dp_max)
    return ans
```

**复杂度**：O(n) 时间 / O(1) 空间（与 53 完全相同）。

**一句话口述（面试会被问"为什么 53 不需要管最小值"）**：

> "53 是加法，`dp[i]=max(dp[i-1]+x, x)`——最小值只可能拖后腿，不用管；
> 152 是乘法，**负数会把最小值翻成最大值**，所以必须同时跟踪 `dp_min`。
> 这是两道题唯一的结构差别。"
