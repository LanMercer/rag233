> **softmax 输出 = 概率分布；注意力 = 对 Value 的加权平均，权重由 Q、K 相似度经 softmax 决定；位置编码 = 给词编座位号。**

## ② 整体结构


| 部件 | 大白话 | 关键点 |
|---|---|---|
| Encoder（编码器） | 阅读理解部 | 整句并行读完，输出每个词"理解了上下文"的表示 |
| Decoder（解码器） | 写作部 | 逐词生成，每步只能看到已生成的词（右移一位） |
| Embedding（嵌入） | 词 → 数字向量 | 计算机只认数字 |
| 输出 | 下一个词的概率分布 | Linear 算分数 → Softmax 变概率 → 取最大/抽样 |

- Encoder 和 Decoder 都堆叠 **N 层**（原论文 N=6），层内结构相同。
- 数据流：`词 → Embedding → 位置编码 → Encoder → Decoder → Linear+Softmax → 概率分布`。

## ③ 注意力（概率语言版）


- **Q（Query）** = 我想查什么
- **K（Key）** = 我能提供什么主题
- **V（Value）** = 我能提供什么内容


三步走：


1. **Q 与所有 K 比相似度** → 得到"分数"
2. **softmax(分数)** → 得到权重（概率分布，每行和为 1）
3. **权重 × V 加权平均** → 得到"融合上下文的新表示"


数学视角（差异化谈资）：


- softmax 输出 = **概率分布**
- 注意力权重矩阵 ≈ **转移概率矩阵**（每行和为 1）："当前词从哪些词收集信息"
- 自注意力 = Q、K、V 都来自同一条句子（句内互相关注）
- 多头注意力 = 多组 Q/K/V 并行，多个视角（细节第 4 天补）

## ④ 位置编码


- **为什么需要**：注意力不分先后。"我爱你"和"你爱我"对注意力来说一样。
- **是什么**：给每个位置一个唯一编号，加在词向量上。
- **一句话**：给词编座位号，让模型知道词序。
