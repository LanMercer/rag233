## 🏗️ 第 2 步：精读第一部分——整体结构：Encoder / Decoder 布局（40~60 分钟）



### 2.1 文章在讲什么任务

文章用**机器翻译**来举例子：输入一句英文 "The animal didn't cross the street because it was too tired"，模型要输出对应的法文。

一开始，Transformer 在文章里是个**黑盒**：你把英文句子丢进去，它吐出法文句子，中间干了啥谁也不知道。文章的第一步，就是把黑盒拆开——里面是两大部分：

- **Encoder（编码器）**：负责"读"。把整句英文读进去，输出每个词"理解了上下文后的表示"。
- **Decoder（解码器）**：负责"写"。一个词一个词地生成法文，每生成一个词，就参考一下 Encoder 的理解结果。

> 🔑 **记住这个对比**：
> Encoder = 一次性读完一整句（**并行的，快**）；
> Decoder = 一个一个往外蹦词（**串行的，慢**，因为下一个词依赖前面已经生成的词）。



### 2.2 "把张量带进画面"——数据是怎么流动的

文章第二节讲的是**数据从哪进、往哪走**。这里的关键概念只有一个：

- **Embedding（嵌入）**：把"词"变成"一串数字（向量）"。比如把 `The` 变成 `[0.3, -0.7, 0.1, ...]` 这样的数字列表。**计算机不认识汉字/英文，只认识数字**，所以一切词都先翻译成数字向量。

流动过程（跟着看文章的图，一个一个节点走）：

```
英文句子
   ↓ （每个词查表变成向量）
词嵌入（Input Embedding）
   ↓ （加上位置信息，第 4 步讲）
位置编码
   ↓
Encoder（N 层，逐层往上走）
   ↓
Decoder（N 层，逐层往上走）
   ↓
Linear + Softmax（输出概率）
   ↓
选概率最大的词，就是下一个词
```

**注意 Decoder 的输入**：生成的时候，Decoder 看到的是"已经生成的词"（文章里叫 shifted right，右移一位——意思是"只看过去，不看未来"）。这个细节今天知道就行，第 4 天讲多头注意力时会再碰到。

### 2.3 用概率语言说一句话（今天第 1 句要记的话）

> **Transformer 的输出不是一个词，而是一个"下一个词的概率分布"。** 比如生成完 "The"，模型其实算出了"下一个词是 xxx"的每个候选词的概率：`P(animal)=0.3, P(man)=0.2, P(dog)=0.1 ...`，然后挑概率最高的那个当输出。

这就是你数学背景的第一个用武之地：**大模型生成 = 每一步从一个概率分布里抽样**。第 6 天调 `temperature` 参数时，你会发现"温度高 = 概率分布更均匀 = 输出更多样"，完全呼应今天的这句话。

## ⭐ 第 3 步：精读第二部分——注意力机制（60~90 分钟，今天最重头）

**这一节是全文章最重要的内容，也是未来所有面试的基础。慢慢读，不急。**

### 3.1 大白话：注意力是什么

读这句话："**The animal didn't cross the street because it was too tired.**"

"it" 指代谁？人脑一秒钟就答上来：指代 "the animal"。你是怎么知道的？因为读到 "it" 时，你的**注意力**自动放在了 "animal"、"cross"、"street" 这些词上，拼出了答案。

**注意力机制就是把这个"划重点"的过程教给机器**：模型在处理每个词时，也会自己决定"我应该多看看句子里的哪些词"。

### 3.2 查字典类比：Q / K / V 是什么

文章用查字典来解释注意力里的三个角色。我们用中文重新讲一遍：


| 角色    | 英文    | 大白话        | 类比          |
| ----- | ----- | ---------- | ----------- |
| **Q** | Query | "我现在想知道什么" | 你要在词典里查的那个词 |
| **K** | Key   | "我能提供什么主题" | 词典里每个词条的标题  |
| **V** | Value | "我能提供什么内容" | 词典里每个词条的正文  |


流程是这样的：

1. 你拿着 **Q（要查的词）**，和词典里所有 **K（词条标题）** 比对相似度——"哪个词条最接近我想查的？"
2. 相似度经过 **softmax** 变成权重——最相关的词条权重最大。
3. 把所有词条的 **V（正文）** 按权重加权平均，合成一个"综合答案"。

> 🔑 **这就是注意力的完整定义，也是今天要背下来的一句话**：
> **注意力 = 对 Value 的加权平均；权重由 Query 和 Key 的相似度经过 softmax 决定。**



### 3.3 用你的数学背景：softmax 输出 = 概率分布

这是今天第二句要记的话，也是你在面试时的"差异化谈资"：

> **softmax 干的事，就是把一堆"分数"变成"概率分布"：每个值都变成 0~1 之间的数，所有值加起来等于 1。**

在注意力里，对同一个词来说，它给所有词算出的权重就是一行概率分布（和为 1）。谁最相关，谁的权重最大。

**数学加成时刻**：你完全可以把注意力权重矩阵看成一张**转移概率矩阵**（你学概率统计肯定见过：每行和为 1、每格是 0~1 的概率）。它的含义是——"当前词从其他词那里收集信息的比例"。第 3 天我们会亲手算出 3 个词的注意力权重矩阵，你到时候会发现它长得就跟马尔可夫转移矩阵一模一样，这是面试时"为什么数学背景适合做 AI"的绝佳例子。

### 3.4 文章的例子：Thinking → Machines

文章用两个词 "Thinking" 和 "Machines" 演示了自注意力（Self-Attention）：

1. "Thinking" 和 "Machines" 各自生成自己的 Q、K、V（就是各自的"查询"、"标题"、"内容"）。
2. 拿 "Thinking" 的 Q，和 "Thinking" 的 K、"Machines" 的 K 各算一次相似度。
3. 相似度经 softmax 变权重（比如 0.88 和 0.12）。
4. 按权重把两个词的 V 加权平均，得到 "Thinking" 这个词"融合了上下文"的新表示。

**跟着文章的图走一遍这个流程**，这是注意力理解的"分水岭"——图看懂了，你就过了最难的一关。

### 3.5 什么是"自注意力"（Self-Attention）

"自"的意思：**Q、K、V 都来自同一条句子里面的词**。一句话里的每个词，都和这句话里的其他词互相关注（包括它自己）。

对比一下，和"自注意力"相对的"**交叉注意力**"（Cross-Attention，第 2 周 RAG 会用到）：Encoder 的输出给 Decoder 提供 K、V。今天先记住"自注意力 = 一句话内部互相关注"就行。

### 3.6 顺带看一眼：多头注意力（Multi-Head Attention）

文章讲完自注意力后，介绍了"多头"：把 Q、K、V 分成几组，**并行**地做几遍注意力，每组关注不同的方面（有的关注语法关系，有的关注指代关系，有的关注远近），最后把结果拼起来。

今天**只要求知道"多头 = 多个视角并行关注"**这一句话，细节（怎么分组、怎么拼接）第 4 天专门学。

### 3.7 复述练习（这段必须复述，今天的核心）

合上文章，把下面这段用自己的话讲出来（可以对着镜子，也可以打字发我）：

> "注意力就是：拿 Q 去和所有 K 比相似度，相似度过 softmax 变成权重（也就是概率分布），再用权重对 V 做加权平均。自注意力就是 Q、K、V 都来自同一个句子。"

讲不流利就再看一遍 3.2~3.4，直到能一口气讲完为止。

## 🔢 第 4 步：精读第三部分——位置编码（20~30 分钟）



### 4.1 为什么需要位置编码

注意力有个"致命缺陷"：**它不分先后**。

"我爱你"和"你爱我"，词完全一样，只是顺序不同。但自注意力在计算时，是把每个词和其他所有词比较——对注意力来说，"我"后面是"爱"还是"爱"后面是"我"，它**根本看不出来**，两个句子会被当成一模一样。

这就坏了：语言里顺序极其重要（"猫咬狗" ≠ "狗咬猫"）。

### 4.2 一句话理解：位置编码 = 给词编"座位号"

解决办法很简单：**给每个位置发一个唯一的编号**，把"我是第 1 个词""我是第 2 个词"这个信息**加**到词向量上。

- 第 1 个词：词向量 + 位置1的编码
- 第 2 个词：词向量 + 位置2的编码
- …

这样，模型看到第 1 个词时，不光知道"这是个什么词"，还知道"它排第几"。

### 4.3 文章里的正弦余弦公式——跳过！

文章介绍了用 `sin` / `cos` 生成位置编码的公式。**这周不要求看懂公式**，你只需要记住三件事：

1. 位置编码是**提前算好**的（不学习，直接给）；
2. 每个位置的编码是**唯一的**（所以模型能区分位置）；
3. 它是**加在词向量上**的（不是拼在边上）。

> 有些新模型（比如 Qwen 用的 RoPE）位置编码方式不同，但"给词编座位号"这个**目的**完全一样。本周只抓目的，不抠实现。



### 4.4 复述练习

一句话回答：为什么需要位置编码？

> 因为注意力不分先后，没有它，"我爱你"和"你爱我"会被当成一样的。

### A. 力扣刷题 2 道（双指针入门）

今天刷题专题是**双指针**。去 [https://leetcode.cn](https://leetcode.cn) 做这两道：

1. **26. 删除有序数组中的重复项**（数组已排序，把重复的删掉，返回新长度）
2. **27. 移除元素**（把等于 val 的元素移走，返回新长度）

**先说说"双指针"是什么（大白话）**：

> 双指针 = 在数组上用**两个手指头**（两个下标）同时从一头往另一头走，一个快一个慢（或一个在前一个在后），边走边配合，实现"一趟搞定"。省得用两层循环（那样慢一倍不止）。

- **26 题的思路**：慢指针 `i` 指向"最后一个不重复的位置"，快指针 `j` 从头扫到尾。只要 `nums[j] != nums[i]`，就把 `nums[j]` 放到 `i+1` 的位置，`i` 前进。一趟下来，`i+1` 就是不重复元素的个数。
- **27 题的思路**：慢指针 `i` 指向"下一个要放的位置"，快指针 `j` 从头扫。只要 `nums[j] != val`，就把 `nums[j]` 放到 `i` 的位置，`i` 前进。最后 `i` 就是新长度。

### B. Python 语法速查（今天补 2 个点）

**1. 列表推导式（List Comprehension）**——Python 最常用的"一行生成列表"写法，刷题和写模型代码天天见：

```python
# 普通写法
squares = []
for x in range(10):
    squares.append(x * x)

# 列表推导式（一行搞定）
squares = [x * x for x in range(10)]
print(squares)   # [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

# 还可以加条件：只要偶数
evens = [x for x in range(10) if x % 2 == 0]
print(evens)     # [0, 2, 4, 6, 8]
```

**2. 字符串切片（Slicing）**——取字符串的一部分，格式 `s[起点:终点:步长]`，注意**终点不包含**：

```python
s = "abcdef"

print(s[1:4])    # 'bcd'（从下标1到下标3，不含下标4）
print(s[:3])     # 'abc'（不写起点 = 从0开始）
print(s[3:])     # 'def'（不写终点 = 到最后）
print(s[::-1])   # 'fedcba'（步长为 -1 = 倒着取，实现字符串反转！）
```

> 小练习（顺手做）：用一行列表推导式，把 `["I", "love", "AI"]` 变成 `["I", "LOVE", "AI"]`（提示：字符串有个 `.upper()` 方法）。

## 📎 附录：文章要点导读（我帮你整理的大白话版）

> 这个导读的作用是**对照自查**：先自己精读，读完对不上号的地方，回来看这节。也可以当"没时间读全文"时的应急替代（但推荐还是自己读）。



### 导读 1：整体结构（对应第 2 步）

- Transformer 是**翻译机**：英文句子进去，法文句子出来。
- 内部 = **Encoder（读）** + **Decoder（写）**，各堆 N 层（原文 N=6）。
- 词先进 **Embedding**（词 → 数字向量），再加**位置编码**，再进 Encoder。
- Encoder 并行读完整句；Decoder 逐词生成，且**只能看到已生成的词**（右移一位）。
- 输出：Linear 层把向量变成"每个候选词的分数"，Softmax 把分数变成**概率分布**，取概率最大的词。



### 导读 2：注意力（对应第 3 步）

- Q = 我想查什么；K = 我能提供什么主题；V = 我能提供什么内容。
- 三步走：Q 与所有 K 比相似度 → softmax 变权重 → 对 V 加权平均。
- 权重和 = 1，是一行**概率分布**；整张权重矩阵 = **转移概率矩阵**。
- 自注意力 = Q、K、V 都来自同一条句子（句内互相关注）。
- 多头注意力 = 多组 Q/K/V 并行，多个视角。



### 导读 3：位置编码（对应第 4 步）

- 问题：注意力不分词序。
- 方案：给每个位置一个唯一编号，加在词向量上。
- 一句话：位置编码 = 给词编座位号。
