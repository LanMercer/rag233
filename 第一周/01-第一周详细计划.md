## 三、每日详细学习内容

### 8/1 周六 · 环境搭建日

**主线（3~4h）：**
1. 安装 Anaconda，创建虚拟环境 `llm`（Python 3.10+）
2. PyCharm 或 VS Code + Jupyter 安装配置
3. GPU 环境验证：`nvidia-smi` 确认驱动 + 安装 CUDA 版 PyTorch（`pip install torch` 自动匹配或按官网命令）
4. 安装核心库：`transformers`、`langchain`、`chromadb`、`accelerate`、`datasets`
5. **验收**：跑通 `torch.cuda.is_available()` 返回 True + 载入最小模型测试

**零散时间：** 力扣 1、217（哈希入门）｜ Python：函数定义与调用、列表/字典操作

**产出：** 环境搭建截图 + 依赖清单 `requirements.txt` + 第一个 commit

### 8/2 周日 · Transformer 图解入门

**主线（3~4h）：**
1. 精读 Jay Alammar《The Illustrated Transformer》中文版（重点：整体结构、Encoder/Decoder 布局）
2. 只看"发生了什么"层面，禁止陷入数学推导
3. 用概率语言重写笔记：*softmax 输出 = 概率分布；注意力 = 对 Value 的加权平均，权重由 Q、K 相似度经 softmax 决定*
4. 画出 Transformer 整体结构图（手绘或 PPT，标注 Encoder、Decoder、多头注意力、位置编码位置）

**零散时间：** 力扣 26、27（双指针入门）｜ Python：列表推导式、字符串切片

**产出：** 结构图草稿 + 一页概念笔记

### 8/3 周一 · 3Blue1Brown 注意力机制可视化

**主线（3~4h）：**
1. 观看 3Blue1Brown《But What Is a Transformer?》系列（共4部，重点第1、2部：注意力机制、softmax 权重）
2. 理解三个关键概念：Q/K/V 的含义、自注意力如何计算、位置编码为什么需要
3. 实践：用 Jupyter 写一个极简 softmax 手算示例（3个词的注意力权重矩阵，10行代码）
4. 结合你的数学背景：把注意力权重矩阵当**转移概率矩阵**理解（每行和为1）

**零散时间：** 力扣 88、121（双指针进阶）｜ Python：类与对象初步

**产出：** softmax 手算 notebook + 概念笔记补全

### 8/4 周二 · 多头注意力与位置编码

**主线（3~4h）：**
1. 3Blue1Brown 第3、4部（多头注意力、为什么需要位置编码）
2. 理解：多头 = 多个"视角"并行关注；位置编码 = 给词排序号（类比：没有它，句子顺序颠倒结果一样）
3. 查看 `torch.nn.Transformer` 源码结构，理解输入/输出 tensor 形状
4. 运行一个官方 Transformer 小 demo（PyTorch 教程中的 sequence-to-sequence 示例）

**零散时间：** 力扣 242、383（哈希计数）｜ Python：文件读写、异常处理

**产出：** 多头注意力 + 位置编码概念笔记

### 8/5 周三 · 结构图定稿 + 微调前置认知

**主线（3~4h）：**
1. 补齐结构图：加上残差连接、LayerNorm、前馈网络，标注每层作用
2. 理解微调概念（只懂"是什么"）：预训练模型 = 通用底座，微调 = 在底座上针对任务调整；LoRA 只改一部分参数
3. 阅读 HuggingFace 文档《Fine-tuning a pretrained model》快速入门页
4. 确认 Qwen 部署的硬件方案：Qwen2.5-7B-Instruct 量化版（`bitsandbytes` 4bit）在 8G+ 显存上的可行性（实际结论：6G 显存用 Qwen2.5-3B 4bit）

**零散时间：** 力扣 283、169（双指针 + 数学思维）｜ Python：常用库速览 numpy 基础

**产出：** 完整结构图 + 微调一页认知笔记
