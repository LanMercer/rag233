## ① 一句话总结（面试版，背下来）

> **多头注意力 = 把 Q/K/V 按维度切分成几组并行算注意力，每组关注一种关系，结果再拼起来——本质是同时算好几张"转移概率矩阵"；位置编码 = 用不同频率的 sin/cos 给每个词编一个唯一"座位号"，没有它，模型分不清"我爱你"和"你爱我"。**

---

## ② 多头注意力（今天新增重点）

### 2.1 为什么需要

- 单头注意力只能用一组 Q/K/V，**一次只能关注一种关系**；
- 一句话里同时有"词性搭配、指代关系、远近关系……"，一个头忙不过来。

### 2.2 怎么做（三步）

```
1. 分头：把 Q/K/V 按维度切成 num_heads 组（每组维度 = d_model ÷ num_heads）
2. 并行算：每个头独立算一遍 Day 3 的三步走（Q·Kᵀ/√d → softmax → ×V）
3. 并头：把所有头的输出按列拼接，恢复成 d_model 维
```

- 代码里的分头：`Q[:, h*head_dim:(h+1)*head_dim]`（切列）
- 代码里的并头：`np.concatenate(heads, axis=1)`（拼列）

### 2.3 数学视角（差异化谈资）

- **多头 = 多张"转移概率矩阵"并行**：每个头一张，每行和为 1，代表一种关注视角；
- 亲手验证过的例子（2 头、6 维、3 词"猫/追/狗"）：
  - 头 1（看"身份"）→ 权重矩阵近似**对角矩阵**（每个词关注自己）；
  - 头 2（看"动物类别"）→ "猫""狗"互相关注（权重 ≈ 0.49），"追"被忽略；
  - 同一句输入，两个头给出**两张完全不同的转移概率矩阵**。

### 2.4 和官方 PyTorch 对答案

- 手写多头注意力的输出 vs `torch.nn.MultiheadAttention(embed_dim, num_heads)`：
  **最大误差 ≈ 1e-6** → 做的是同一件事，官方只是封装 + 用训练学出来的 W。

## ③ 位置编码（今天新增重点）

### 3.1 为什么需要

- 注意力**不分先后**：打乱句子顺序，注意力输出只跟着乱，模型察觉不到顺序变化；
- "我爱你"和"你爱我"在模型眼里可能是同一句话。

### 3.2 是什么（代码长这样）

```
偶数维: pe[pos, 2i]   = sin(pos / 10000^(2i/d_model))
奇数维: pe[pos, 2i+1] = cos(pos / 10000^(2i/d_model))
位置编码 = 不同频率的正弦/余弦组合，每个位置一个唯一向量
```

- 位置编码**加**在词向量上（不是拼接）；
- 可视化：`positional_encoding.png` 热力图——每一行是一个位置的"频率指纹"，互不相同。

### 3.3 数学视角（差异化谈资）

- 不同维度用不同频率 → 每个位置得到唯一**"频率指纹"**（和信号处理/傅里叶分解同源）；
- 关键实验结论：不加位置信息，"我爱你 / 你爱我"的注意力输出**完全一样**（只是顺序被换）；加上位置信息后**不一样了**；
- 灵魂实验：把 seq2seq demo 的位置编码关掉 → **倒序任务 loss 几乎不降** → 位置编码必不可少。

## ④ torch.nn.Transformer 结构（今天新增，代码级）

```
Transformer
 ├─ Encoder（读） = N 层 TransformerEncoderLayer
 │    每层：多头注意力 → Add&Norm → 前馈网络 → Add&Norm
 └─ Decoder（写） = N 层 TransformerDecoderLayer
      每层：带掩码多头注意力 → Add&Norm → 多头注意力 → Add&Norm → 前馈 → Add&Norm
```

- 张量形状（`batch_first=False`）：一律 `(序列长度, 批量, 维度)`；
- Encoder/Decoder 只改内容不改形状：`(长, 批, 维)` 进 → `(长, 批, 维)` 出；
- 最后 `Linear`：`d_model` 维 → `vocab_size` 维，配合 softmax = "下一个词的概率分布"。
