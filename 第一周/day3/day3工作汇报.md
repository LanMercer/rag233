## 四、踩坑与解决（过程真实记录）

| # | 问题 | 解决办法 |
|---|---|---|
| 1 | 不知道 Jupyter 怎么用、不确定电脑上有没有 | 检测确认 `llm` 环境自带完整 Jupyter（jupyterlab 4.6.2 / notebook 7.6.1 / ipykernel 7.3.0），无需新装；推荐用 VS Code 直接双击打开 `.ipynb` 运行 |
| 2 | 在 VS Code 运行 notebook 后，**终端没有输出、面板显示一堆变量**，误以为没跑成 | 澄清：notebook 的输出不在终端里，而是在**每个代码格子正下方**；下方"变量面板"里出现的 X/Q/K/V/scores/weights/out 恰恰是**运行成功的证据**。滚动格子即可看到 3×3 矩阵输出 |
| 3 | PowerShell 终端直接运行脚本时中文显示乱码 | 是控制台编码问题（非代码问题），在 VS Code 终端或 Jupyter 里运行显示正常 |
| 4 | Python 基础薄弱，脚本看不懂 | 已将 `softmax_attention.py` 重写为**逐行教学版**：开头新增"课前语法速查表"（列表/for/enumerate/f-string/函数/@矩阵乘法/列表推导式等逐个讲解），每行代码配大白话注释 |
