## ② 整体结构（在 Day 2 基础上补一处）

- Encoder（阅读理解部）：整句并行读 → 输出每个词"理解了上下文"的表示

## ③ 注意力（概率语言版）—— 今天补全的重点

### 3.1 角色（不变，但要懂更深）

- **Q（Query）** = 我想查什么 → 拿去和所有 K 比对
- **K（Key）** = 我能提供什么主题 → 被 Q 比对
- **V（Value）** = 我能提供什么内容 → 被加权平均

> 一句话：**Q 问，K 答，V 给**。

### 3.2 计算流程（今天新增）

```
Q = X·Wq    K = X·Wk    V = X·Wv     （X = 词向量矩阵，W 为可学习的变换矩阵）
scores = Q·Kᵀ / √d                    （相似度 + 缩放）
weights = softmax(scores)             （每行归一化，每行和为 1）
输出 = weights · V                    （加权平均，融合上下文）
```

### 3.3 数学视角（差异化谈资，今天新增）

- **softmax 输出 = 概率分布**（非负、和为 1）；
- **注意力权重矩阵 ≈ 转移概率矩阵**（每行和为 1、每格 0~1）——第 i 行 = 词 i 从各词收集信息的比例；
- **为什么除以 √d**：d 个独立分量乘积求和，方差 = d（方差可加性）；除以 √d 让方差回到 1，防止分数过大 → softmax 退化成"one-hot" → 梯度消失；
- 点积相似度 ≈ 余弦相似度 × 向量长度（Q·K 同时包含"方向是否一致"和"长度"）。

### 3.4 亲手算出来的例子（今天新增，放截图）

3 词句子（one-hot 词向量）的权重矩阵：

```
猫 [0.576 0.212 0.212]
追 [0.212 0.576 0.212]
狗 [0.212 0.212 0.576]
```

- 每行和为 1 → 每行是概率分布；
- 对角线最大 → 最关注自己（one-hot 只有自己和自己像）；
- 改成"猫/狗共享'动物'维度"的词向量后，**"猫""狗"对彼此的权重明显变大（0.212→0.468），"追"被忽略（0.212→0.063）** → 词向量承载语义，注意力自动聚焦同类词。

## ④ 位置编码（视频版加深）

- 为什么需要：注意力不分先后，"我爱你"和"你爱我"会被当成一样的；
- 是什么：给每个位置一个唯一编号，加在词向量上；
- 一句话：给词编座位号。视频演示了"打乱顺序 → 注意力结果不变"，直观印证了这一点。
