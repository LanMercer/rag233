### 2.1 视频 1 讲了什么（先剧透，带着地图看）

## ⭐ 第 3 步：视频 2 —— 自注意力怎么算（矩阵化计算）（60~90 分钟）



### 3.1 视频 2 讲了什么（先剧透）

视频 1 讲"为什么需要注意力"，视频 2 讲"**注意力到底怎么算**"——从单个词的视角，升级到**整句话一起算**（矩阵化）。这也是你第 5 步手算要复现的东西。

核心就 3 行：

```
第 1 步   Q 和所有 K 做点积        → 相似度分数（谁和谁更相关）
第 2 步   softmax（按行归一化）     → 权重矩阵（每行和为 1）
第 3 步   权重 × V 加权平均         → 每个词"融合上下文"的新表示
```



### 3.2 数学加成时刻：为什么除以 √d（今天第 2 句要背的话，面试加分项）

视频 2 里有个"细节"：算完 Q·Kᵀ 之后，要**除以根号 d**（d 是向量维度）。视频里说这是为了"防止数值爆炸"。**你用概率统计的知识能讲得更深**：

> Q·Kᵀ 是 d 个独立分量乘积之和，如果每个分量方差是 1，那么求和结果的**方差就是 d**（独立同分布变量方差可加）。除以 √d 后，方差回到 1——**相当于对分数做了"标准化"，让 softmax 的输入不会因为维度大而方差过大**。方差太大 → softmax 会接近"one-hot"（一个 1、其余 0）→ 梯度消失。

这一小段如果面试被问到"为什么除以 √d"，别人只能背答案，你能讲出"方差可加性"——这就是数学背景的差异化。

### 3.3 和 Day 2 的关系：今天学的就是昨天那句话的"展开"

昨天你背的是"注意力 = 对 Value 的加权平均，权重由 Q、K 相似度经 softmax 决定"。今天视频 2 把它拆成了 3 个数学动作。**背句子是 Day 2 的事，懂句子是今天的事。**

### 5.2 逐行看懂脚本（重要，跟着代码走一遍）

打开 `softmax_attention.py`，我带你逐段看（脚本里也有注释）：

**第 1 段：造 3 个词的词向量**

```python
words = ["猫", "追", "狗"]
X = np.eye(3)     # 单位矩阵：猫=[1,0,0] 追=[0,1,0] 狗=[0,0,1]
```

- `np.eye(3)` = 3×3 单位矩阵，每一行代表一个词的词向量（one-hot 形式，极简版，方便手算）；
- 真实模型的词向量是**学出来的**、几百上千维的，这里用最简的，只看"流程"。

**第 2 段：生成 Q / K / V**

```python
Wq = Wk = Wv = np.eye(3)
Q = X @ Wq        # 每个词的 Query
K = X @ Wk        # 每个词的 Key
V = X @ Wv        # 每个词的 Value
```

- 真实模型里 Wq/Wk/Wv 是**训练学出来的矩阵**，视频 2 讲的就是它们；这里全用单位矩阵 = "Q/K/V 就是词向量本身"，把干扰降到最低。

**第 3 段：三步走**

```python
scores = Q @ K.T                 # 第 1 步：相似度分数
weights = np.array([softmax(r) for r in scores])   # 第 2 步：softmax 归一化
out = weights @ V                # 第 3 步：加权平均
```

- `Q @ K.T`：Q 矩阵（3×3）乘 K 的转置（3×3），得到 3×3 的分数矩阵 `scores[i][j]` = 词 i 对词 j 的相似度；
- `softmax(r)` 对每一行做归一化 → 每行和为 1（**这就是概率分布**）；
- `weights @ V`：权重矩阵 × Value 矩阵 = 每个词融合上下文后的新向量。



### 5.3 看懂输出：3×3 权重矩阵的秘密

现在的权重矩阵是：

```
猫 [0.576 0.212 0.212]
追 [0.212 0.576 0.212]
狗 [0.212 0.212 0.576]
```

三个发现（都值得记进笔记）：

1. **每行和为 1** → 每一行都是一个概率分布；
2. **对角线最大（0.576）** → 每个词最关注自己（因为 one-hot 词向量只有自己和自己"像"）；
3. **非对角线相等（0.212）** → "追"对"猫"和"狗"的关注度一样——**因为 one-hot 词向量看不出任何词义关系**。真实模型用学习出来的词向量，"追"就会明显更关注"猫""狗"（动物相关）而不是无关词。这就是为什么词向量要"学"，而不是直接用 one-hot。

> **注意力权重矩阵 ≈ 一张"信息转移概率矩阵"：第 i 行的每个数，表示"词 i 从其他词那里收集信息的比例"。**

### B. Python 语法速查（今天补 1 个点：类与对象初步）

今天要补的语法是 **类（class）与对象（object）**。为什么现在学？因为从下周开始，你要用 `transformers` 等库，里面全是"对象"（比如 `model = AutoModel.from_pretrained(...)` 就是一个对象，`model.generate(...)` 是调用它的方法）。不懂"类"，你连库的代码都读不明白。

**大白话类比：**

> 类 = **模具**（生产流程说明书）；对象 = 用模具造出来的**产品**。
> 比如"手机"是一个类（有品牌、颜色这些属性，有打电话、拍照这些方法），你手上的 iPhone 就是"手机"类的一个对象。

**10 分钟学会 3 件事**（抄下来在终端试一遍）：

```python
# 1. 定义类：class + __init__(初始化)
class 学生:
    def __init__(self, 名字, 分数):   # __init__ = 造对象时自动执行，self = 对象自己
        self.名字 = 名字              # 属性：给这个对象存一个"名字"
        self.分数 = 分数

    def 报分数(self):                # 方法：对象能干的动作
        print(f"{self.名字} 考了 {self.分数} 分")

# 2. 创建对象：类名(参数) 就会自动调用 __init__
张三 = 学生("张三", 92)
李四 = 学生("李四", 85)

# 3. 用对象：访问属性 / 调用方法
print(张三.名字)      # 张三
张三.报分数()         # 张三 考了 92 分
```

**关键点只需记一句**：

> `self` = "这个对象自己"。类里所有属性方法都通过 `self.xxx` 操作，这样每个对象才各存各的数据，互不干扰。

> 小练习（顺手做）：给"学生"类加一个方法 `是否及格`，分数 ≥ 60 返回 `"及格"`，否则返回 `"不及格"`，然后让张三、李四各调一次。

> 推荐快速资料：廖雪峰 Python 教程（[https://liaoxuefeng.com/books/python/](https://liaoxuefeng.com/books/python/)），只读"面向对象编程"一节的前半部分（类和实例、`__init__`），15 分钟搞定。

## 📎 附录一：要点导读（看完视频后对照自查）



### 导读 1：Q / K / V（对应第 2 步）

- **Q（Query）** = 我在找什么 → 拿去和所有 K 比对
- **K（Key）** = 我提供什么主题 → 被 Q 比对
- **V（Value）** = 我提供什么内容 → 被加权平均的对象

> 一句话：**Q 问，K 答，V 给**。Q 和 K 决定"关注谁"，V 决定"拿走什么"。



### 导读 2：自注意力计算（对应第 3、5 步）

```
输入 X（n 个词 × d 维）
  → Q = X·Wq, K = X·Wk, V = X·Wv
  → scores = Q·Kᵀ / √d        （相似度 + 缩放，防止方差过大）
  → weights = softmax(scores)  （每行归一化，每行和为 1）
  → 输出 = weights·V           （加权平均，融合上下文）
```



### 导读 3：数学视角（对应第 6 步）

- softmax 输出 = 概率分布（非负、和为 1）
- 权重矩阵 = 转移概率矩阵（每行和为 1、每格 0~1）
- 除以 √d = 方差标准化（独立同分布方差可加：方差 d → 除以 √d 回到 1）
