## 四、踩坑与解决（过程真实记录）

| # | 问题 | 解决办法 |
|---|---|---|
| 1 | 定稿结构图脚本生成时，图片里出现"方块"缺字：matplotlib 警告 `Glyph 8321 (x₁) missing from font Microsoft YaHei`——微软雅黑字体**没有下标数字字形**，脚本里 `x₁/x₂` 等下标写法画不出来 | 把脚本里所有下标字符（x₁/x₂/W₁/W₂）全部改成普通数字写法（x1/x2/W1/W2），重新运行后警告消除、图片文字全部正常显示 |
| 2 | PowerShell 直接运行含中文输出的脚本时，终端显示乱码（GBK 控制台编码问题，非代码问题） | 运行输出用 `cmd /c "python xxx.py > 文件.txt 2>&1"` 重定向为 UTF-8 文件再读取核对；用户在 VS Code 终端直接运行则显示正常 |
| 3 | `lora_math_demo.py` 若矩阵接近奇异，最小二乘求解可能数值不稳 | 在正规方程中加入 `λI`（λ=1e-6）防奇异，输出与理论值完全一致（如 r=3 时 ΔW 近似误差精确为 0.0000） |
| 4 | 显存测算的"运行开销"（CUDA 上下文 + KV Cache + 激活值）是经验估算，不同来源数字略有出入 | 在脚本和教程中均注明"以第 2 周部署时 `torch.cuda.memory_allocated()` 实测为准"，估算值只用于定方案，不影响"3B 4bit ≈ 3.0GB 可行、7B fp16 装不下"的结论 |
