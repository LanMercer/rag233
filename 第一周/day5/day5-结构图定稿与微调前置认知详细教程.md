> 第 1 步任务对应周计划 8/5 第 1 条："补齐结构图：加上残差连接、LayerNorm、前馈网络，标注每层作用"。



### 1.1 先认识今天的三件套（大白话 + 数学视角）

你在 Day 2 的结构图里见过 `Add & Norm` 和 `Feed-Forward` 这些小方块，但当时没细讲。今天把它们拆开，一个词一个词讲透。三个都是 Transformer 的**标准零件**，Qwen 里也有。

**① 残差连接（Residual Connection，残差 = 和基准值的差；连接 = 加一条通路）**

- **它是什么**：把子层的输出和子层的输入**原样相加**。公式一句话：
`输出 = x + 子层(x)`
- **大白话**：子层（比如注意力）负责"加工"，残差连接就是一条**高速公路**——加工结果不管好赖，原始的 x 都有一份"备份"直接送到后面，加工得再好也不会把原始信息弄丢。
- **数学视角**：`x + 子层(x)` 里的 `x` 就是**恒等映射**（Identity Mapping，什么都不干、原样返回的映射）。把模型想成一个"叠罗汉"，每一层都在恒等映射上加一点小改动——就算某些层学不到东西，模型也至少不会变差。更重要的是：训练时算梯度（梯度 = 损失对每个参数的变化率），信息可以从最后一层**沿着这条高速公路一路抄近道**传回最前面，解决深层网络的"梯度消失"问题（梯度消失了 = 前面的层学不动 = 模型白叠那么多层）。

> 一句话记住：**残差连接 = 给梯度留一条直通的高速公路，顺便保证"加了层至少不会更差"。**

**② LayerNorm（层归一化，Layer = 层；Norm = 归一化/标准化）**

- **它是什么**：把数据（每个词的特征向量）**归一化**：先算均值和方差，然后把每个数变成 `(数 - 均值) / 标准差`，让这一组数据的均值为 0、方差为 1，最后再乘一个可学习的缩放系数 γ、加一个可学习的偏移 β（让模型决定"要不要放大/平移"）。
- **大白话**：就像考试后**标准分**——全班平均分 70、标准差 10，你考 80 就变成 1 分（超过均值 1 个标准差）。LayerNorm 就是给模型内部的每个"班级"算标准分，让数值都落在差不多的范围内，模型训练起来更稳定、更快。
- **数学视角**：这就是你统计里学过的**数据标准化**（Standardization，把数据变成均值 0、方差 1）。为什么用得上：神经网络中间层的数值如果忽大忽小，优化器（调参算法）会无所适从；标准化后数值稳定，训练不容易"发散"。

> 一句话记住：**LayerNorm = 给每一层的数据算"标准分"，让训练又快又稳。**

**③ 前馈网络（Feed-Forward Network，缩写 FFN；Feed-Forward = 数据单向往前流）**

- **它是什么**：两层线性变换夹一个激活函数（激活函数 = 给模型引入"弯折"能力的非线性函数，ReLU 是最常用的一种，公式 `ReLU(z) = max(0, z)`，比 0 大的留着、比 0 小的掐成 0）。公式：
`FFN(x) = W2 · ReLU(W1·x + b1) + b2`
（W1、W2 是可学习的权重矩阵，b1、b2 是偏置；· 是矩阵乘法）
- **大白话**：注意力负责让词与词**交换信息**（"谁该注意谁"）；FFN 负责**每个位置独立地加工一下**这些信息（"这句话的主语是啥、感情是啥"）。打个比方：注意力是开会（同事之间交流），FFN 是开完会各自回工位写总结。两个模块各干各的活，互相配合。
- **数学视角**：注意力的输出经过 FFN，等于对每个词做一次**非线性变换**（两层线性 + ReLU 能逼近任意函数，数学上这叫"万能近似"）。换句话说，FFN 给模型提供了表达能力——没有它，多层线性变换叠起来还是线性，模型永远学不会复杂规律。

> 一句话记住：**注意力负责"交换"，FFN 负责"思考"——每个词独立把信息加工成更抽象的特征。**

**它们仨怎么组合成一层？**（这是今天的重点图）

标准"子层包装"模式：

```
x → [多头注意力] → ⊕残差(x + Attn(x)) → LayerNorm → [FFN] → ⊕残差(x1 + FFN(x1)) → LayerNorm → 输出
```

即：**每个子层外面包一层"残差加法 + LayerNorm"**。Day 2 图里那个 `Add & Norm` 小方块，拆开就是"残差加法 ⊕（Add）+ 层归一化（Norm）"两件事。

## 🧊 第 2 步：微调前置认知——预训练 vs 微调 vs LoRA（60~90 分钟）⭐

> 第 2 步任务对应周计划 8/5 第 2、3 条："理解微调概念（只懂'是什么'）：预训练模型 = 通用底座，微调 = 在底座上针对任务调整；LoRA 只改一部分参数"＋"阅读 HuggingFace 文档"。



### 2.1 三个名词，先建立直觉（20 分钟）

**① 预训练（Pre-training，Pre = 预先；Training = 训练）**

- **它是什么**：在**海量通用文本**上训练模型，让它学会"语言的一般规律"——词和词怎么搭配、一句话大概什么意思。这个阶段极其烧钱（几万张显卡跑几个月），由大公司完成。
- **大白话**：相当于一个刚毕业的大学生，**综合素质好、什么都会一点**，但还不专精任何具体业务。
- **概率语言**：预训练就是在学一个"先验分布"——给定上文，下一个词的概率分布 `P(下一个词 | 上文)`。你 Day 3、4 学的 softmax、注意力、seq2seq 全部是这套东西。
- **结果**：训练完得到的模型叫**预训练模型（Pre-trained Model）**，就是我们常说的"通用底座"——Qwen、GPT、Llama 都是。

**② 微调（Fine-tuning，Fine = 精细地；Tuning = 调）**

- **它是什么**：在预训练模型的基础上，用**你自己任务的数据**继续训练，让模型"专攻"你的活。比如拿几千条客服问答，把 Qwen 调成"客服机器人"。
- **大白话**：给这个大学生**上几个月的在职培训**，把他从"什么都懂一点"变成"你的业务专家"。
- **关键**：微调**不是从零开始**——底座里几亿参数的"通用常识"都保留着，我们只做"最后一公里的调整"。
- **概率语言**：把底座学到的先验分布 `P(词|上文)`，往你任务的方向"拉一拉"，让它更会回答你的问题。

**③ LoRA（Low-Rank Adaptation，Low-Rank = 低秩；Adaptation = 适配）**

- **它是什么**：微调的一种**省内存做法**。完整微调要更新所有参数（7B 模型 = 70 多亿个数字都要改）；LoRA 的做法是：**底座权重（W0）冻住一个都不改**，只在旁边加两个**很小的矩阵 B 和 A**（它们的乘积 B·A 近似表示"微调需要的改动量 ΔW"），只训练这两个小矩阵。
- **大白话**：不改简历本身，而是贴一张小小的"便利贴"在上面注明"此人在 XX 领域有特长"。便利贴很小很便宜，撕掉也不伤原简历。
- **为什么叫"低秩"**：秩（Rank）是线性代数里"矩阵有效维度"的概念。研究发现：微调时模型真正需要改动的地方很少——ΔW 大多数"方向"上几乎不动，用一个**低秩**的小矩阵就能近似表达。你的 SVD 知识在这里直接用上了。

> **一句话记住（面试版）**：预训练给一个"通用底座"，微调是在底座上针对任务继续训练，LoRA 是把"微调的改动"限制在一个低秩小空间里（只训练 B·A），省显存、省时间、还保留底座的大部分旧知识。



### 2.2 用数学 demo 亲手验证（40 分钟）⭐

概念听懂了，还要亲手算一遍。我写好了 `lora_math_demo.py`——**不下载任何模型**，纯 numpy 数学模拟"预训练 → 微调 → LoRA"全过程。

**先认识这个脚本的"五件套"**（回顾 Day 4 学过的判断标准——是不是机器学习/深度学习，就看有没有这五件套）：


| 五件套        | 本脚本里的对应物                   | 一句话作用           |
| ---------- | -------------------------- | --------------- |
| 1. 模型      | 线性回归 `y = X·W`             | 用权重矩阵 W 把输入变成预测 |
| 2. 数据      | 程序随机生成的任务A（通用任务）与任务B（特定任务） | 学习的"课本"         |
| 3. 损失函数    | 均方误差 MSE（预测与答案差的平方的平均）     | "打分尺"：预测离答案差多远  |
| 4. 优化器     | 最小二乘闭式解（正规方程，一步算到最优）       | 算出最优权重          |
| 5. 训练 + 测试 | 在训练数据上拟合，再用新数据测"泛化能力"      | 调好参数 + 验证真学会了   |


**运行它**（llm 环境、day5 文件夹）：

```
python lora_math_demo.py
```

**你会看到**（这是本脚本在你电脑上的真实输出）：

```
==============================================================
1. 预训练（Pre-training）：在任务 A 上训练出一个通用底座 W0
==============================================================
预训练完成。W0 在任务A（通用任务）上的误差 : 0.000000
                    W0 在任务B（特定任务）上的误差 : 4.052495
→ 结论：底座 W0 把任务 A 学得很好（误差≈0），但完全不懂任务 B。

==============================================================
2. 完整微调（Full Fine-tuning）：用任务 B 的数据把 W0 所有参数再训练一遍
==============================================================
完整微调后，Wf 在任务A上的误差 : 3.933165  （预训练时≈0）
                 Wf 在任务B上的误差 : 0.000000  （学会新任务了）
→ 结论：完整微调学会了任务 B，但把任务 A 忘光了——这就是"灾难性遗忘"。
```

**看到这里先停一下，重点理解两个结论：**

1. 预训练完，底座 W0 在任务 A 上误差 **0.000000**（学得很好），在任务 B 上误差 **4.05**（完全不懂）；
2. 完整微调后，任务 B 学会（0.000000），但任务 A 从 0 飙到 **3.93**——**把旧的忘了**。这就是面试常说的**灾难性遗忘**（Catastrophic Forgetting，模型学新任务时把旧任务能力冲掉了）。

继续往下看 LoRA 的数学本质：

```
==============================================================
3. LoRA 的数学本质：微调其实只改了一个"小增量" ΔW = Wf - W0
==============================================================
ΔW 的形状 : (8, 3)（8 行 × 3 列）
ΔW 的奇异值（singular values，衡量每个方向的重要性）: [2.4495 2.     1.4142]
→ 结论：奇异值一共只有 3 个（8×3 的矩阵秩最多为 3），说明 ΔW 本身是低秩的。

LoRA 的做法：不直接改 W0，而是把 ΔW 近似成两个小矩阵的乘积 ΔW ≈ B·A，
其中 B 是 8×r、A 是 r×3，r 远远小于 8（这里 r 取 1、2、3）→ 参数大大变少。
  r=1 : LoRA 后 任务A误差=2.0049 | 任务B误差=1.9758 | ΔW近似误差=0.7071
  r=2 : LoRA 后 任务A误差=3.3076 | 任务B误差=0.7301 | ΔW近似误差=0.4082
  r=3 : LoRA 后 任务A误差=3.9332 | 任务B误差=0.0000 | ΔW近似误差=0.0000
→ 结论：r 越小，更新越"温和"（保留旧知识多、学新任务少）；
        r 越大，越接近完整微调（新任务学得好、但忘得也多）。
```

**这段是全脚本的灵魂，一行行看：**

- `ΔW = Wf - W0`：微调到底改了什么？就是把底座权重从头到尾减一遍，得到"改动量"。这个改动量就是微调的全部内容。
- `奇异值 [2.4495 2. 1.4142]`：奇异值（Singular Value）= 衡量矩阵每个"方向"的重要程度，大奇异值 = 重要的方向。这里只有 3 个奇异值，说明 ΔW 的"有效维度"最多 3 个——**它是低秩的**（秩 = Rank，矩阵有效维度的个数，你线性代数里学的）。
- **LoRA 的公式**：把 ΔW 拆成 `B·A`（B 是 8×r，A 是 r×3），r 就是"秩"。看结果：
  - r=1：改动被压缩到 1 个方向 → 任务 B 学得半生不熟（误差 1.98），但任务 A 保留得最好（2.00）；
  - r=2：折中（任务 B 0.73，任务 A 3.31）；
  - r=3：和完整微调几乎一样（任务 B 0.0000，任务 A 3.93）——因为秩=3 正好把 ΔW 完整表达了（近似误差 0.0000）。
- **结论**：LoRA 的 `r` 就是"你想让模型改动多大"的旋钮。真实场景里我们选个小 r（比如 8），既能把任务学会，又因为改动被限制在低秩空间里，底座的大部分旧知识得以保留。

再看真实大模型的模拟（这部分验证"为什么 ΔW 可以放心用低秩近似"）：

```
==============================================================
4. 真实场景：为什么 ΔW 可以放心地用低秩近似？（用 512×512 的大矩阵模拟）
==============================================================
ΔW 的前 20 个奇异值（第 16 个之后几乎全是 0）：
  610.17  590.12  568.09  556.69  541.56  531.56  527.32  503.71  491.94  481.29  472.98  467.00  458.68  434.92  426.75  407.80  0.00  0.00  0.00  0.00
→ 结论：真实微调学到的 ΔW，绝大多数"方向"上几乎不动，只有少数几个方向
        在变。所以用 r=16 的低秩 B·A 就能几乎无损地表示它。
用 r=16 近似 ΔW 的误差 : 1.63e-15  → 几乎无损！
```

- 这是一个 512×512 的大矩阵，人为构造"真实改动只发生在 16 个方向上"：奇异值前 16 个很大、从第 17 个开始全是 **0.00**。
- 用 r=16 的低秩近似表示它，误差 **1.63e-15**（小数点后 15 位都是 0）——**几乎无损**。这就是"ΔW 是低秩的"最直观的证据：大模型微调时，真正在变的参数方向极少。

最后是 LoRA 的**参数账**（为什么 LoRA 省显存）：

```
==============================================================
5. 参数账：全量微调 vs LoRA（这就是 LoRA 省显存的原因）
==============================================================
对一个 d×d 的权重矩阵：
  全量微调：训练 d² 个参数；  LoRA：只训练 B( d×r ) + A( r×d ) = 2·d·r 个参数
  节省比例 = 1 - (2·d·r)/d² = 1 - 2r/d

  例：d=512, r=16 → 全量=262,144 个参数，LoRA=16,384 个参数，节省 93.75%
  例：d=3584, r=8 → 全量=12,845,056 个参数，LoRA=57,344 个参数，节省 99.55%

以 Qwen2.5-7B 为例（隐藏维度 d=3584，28 层，每层有 q/k/v/o 共 4 个投影矩阵）：
  LoRA 只训练 q/k/v/o 的增量：6,422,528 个参数
  全模型参数：7.61e+09（约 76.1 亿）
  训练的参数只占全模型的 0.084%
→ 这就是面试常说的"LoRA 只训练不到 1% 的参数"。
```

**这段的数学一眼看懂：**

- 全量微调一个 d×d 矩阵要训练 **d²** 个参数；LoRA 只训练 B（d×r）+ A（r×d），共 **2·d·r** 个参数；
- 节省比例 `1 - 2r/d`：Qwen2.5-7B 的隐藏维度 d = 3584，用 r = 8，节省 **99.55%**；
- 全模型 76.1 亿参数，LoRA 只动 q/k/v/o 四个投影矩阵的增量，训练量只有 **642 万个参数 ≈ 全模型的 0.084%**。

> 💡 为什么省显存？训练一个参数需要存"参数本身 + 梯度（变化率）+ 优化器状态（调参历史）"，约等于 3 份拷贝。全量微调 76 亿参数 = 3 份 76 亿，你的 6G 显存想都别想；LoRA 只训练 642 万个参数 = 3 份 642 万，显存占用骤降——第 3 周微调 Qwen 时全靠它。



### 2.3 面试一句话版（背下来）

> **预训练模型 = 在海量通用数据上学出"语言先验"的通用底座；微调 = 在底座上用任务数据继续训练，把通用能力定向到你的任务；LoRA = 冻结底座权重，只训练一个低秩增量 B·A（r 很小），以不到 1% 的参数代价完成微调，省显存还保留底座知识。**

### 4.1 先懂"量化"是什么（10 分钟）

- **量化（Quantization，量 = 数值，化 = 压缩）**：把模型里每个参数从 32 位/16 位的数字，压缩成 8 位甚至 4 位的数字，让模型占显存变小。代价是精度略降（4bit 模型回答质量只差一点点，肉眼几乎看不出）。
- **bit 的含义**：一个参数用几个二进制位表示。32 位 = 4 字节、16 位 = 2 字节、8 位 = 1 字节、4 位 = 0.5 字节。
- **bitsandbytes**：一个专门做低精度量化的库（Day 1 已装好），第 6 天加载 Qwen 时用它开 4bit。
- **NF4**：bitsandbytes 里的一种 4bit 量化格式（NormalFloat4，专门为神经网络设计的分布），效果最好，第 6 天直接用。
- **KV Cache（缓存）**：生成时把历史"键值对"存起来加速（Day 3 的 K/V），也占显存——所以"合计显存 = 权重 + 运行开销（含 KV Cache）"。

> **为什么 6G 是道坎**：7B 模型全精度（fp16）光权重就 15GB，6G 显卡连门都进不去；只有把权重压到 4bit（3.8GB）+ 运行开销（约 1.8GB）≈ 5.6GB，才勉强塞进 6G。

### 5.1 今天的三个数学视角（都要写进笔记）

**视角 1：残差连接 = 恒等映射 + 小扰动**
`x + 子层(x)` 里的 `x` 是恒等映射。整张网络可以看成"恒等映射被逐层修正"——数学上这就是一种**不动点迭代**的思想，保证深了不会差。

**视角 2：LayerNorm = 数据标准化**
`(x - 均值) / 标准差` 再缩放平移——和你统计里学的标准化一模一样。为什么好用：神经网络训练时希望每层输入数值稳定，标准化正是干这个的。

**视角 3：LoRA = 低秩近似（SVD 的经典应用）**
微调的改动量 ΔW 在真实场景中是低秩的（奇异值绝大多数≈0）→ 用 `B·A`（秩 r）近似 → 参数从 d² 降到 2dr。这是你线性代数强项的直接变现，面试时可以从"为什么 ΔW 是低秩的"讲到"Eckart–Young 定理（最佳低秩近似就是截断 SVD）"。

**思路提示（想 10 分钟后再看）：**

- **283 的思路**：双指针（两个"下标"同时往后走）——一个慢指针 `i` 负责"下一个非零数该放哪"，一个快指针 `j` 负责"找到下一个非零数"，把非零数依次搬到前面，最后剩下的位置全填 0。**一趟遍历，O(n) 时间、O(1) 额外空间**。
- **169 的思路（数学视角）**：如果某个数出现超过一半，那么"两个不同数互相抵消"（摩尔投票，Boyer-Moore Voting）之后，**最后剩下来的就是它**。用你的数学直觉想：超过一半 = 哪怕每遇到一个不同数就抵消一次，它也抵消不完，必胜。这题的"数学加成"就在这——面试时用"超过一半 = 抵消不完"这句概率语言讲，特别加分。

### 导读 1：三件套（对应第 1 步）


| 组件        | 公式                    | 作用          | 一句话    |
| --------- | --------------------- | ----------- | ------ |
| 残差连接      | `x + 子层(x)`           | 防梯度消失、保底不更差 | 高速公路   |
| LayerNorm | `(x-均值)/标准差 × γ + β`  | 数值稳定、训练快    | 算标准分   |
| 前馈网络 FFN  | `W2·ReLU(W1·x+b1)+b2` | 每词独立加工      | 开会后的总结 |


- 标准"子层包装"模式：**子层 → 残差加法 → LayerNorm**（每个子层外面包一层）。



### 导读 2：预训练 / 微调 / LoRA（对应第 2 步）


| 名词   | 做什么              | 改什么参数      | 显存压力      |
| ---- | ---------------- | ---------- | --------- |
| 预训练  | 海量通用文本学"语言先验"    | 全部（大公司做）   | 巨大        |
| 完整微调 | 任务数据继续训练         | 全部（70 多亿个） | 巨大，6G 扛不住 |
| LoRA | 冻结底座，只训练低秩增量 B·A | 不到 1%      | 小，6G 可跑   |


- 微调改动量 ΔW 是低秩的（奇异值绝大多数≈0）→ 用 B·A（秩 r）近似；
- 参数账：`d² → 2dr`，节省 `1 - 2r/d`；Qwen2.5-7B（d=3584, r=8）节省 99.55%。
