**今天结束时的"验收标准"一句话：**

> 你手里有一张**项目架构图**（四层组件齐活）+ 一份 **20 条评测问题集**（两类各半，每条可判定）+ 一次**接口切换冒烟测试**记录（微调模型已能通过 `/v1/chat/completions` 正常问答）。

**和你的数学背景接上的点（今天会反复出现）：**

- **项目定性 = 定义支持集**：把"所有可能的问题"圈定在"机器人领域 + 资料能覆盖"这个子集里，模型只需在这个子集上做得好——和统计里"先定总体、再抽样"一个道理；

### 1.3 MVP 边界（"不做"清单）⭐ 关键

MVP = Minimum Viable Product（最小可行产品）。重点是**想清楚"不做什么"**：


| 不做       | 为什么不做                                      |
| -------- | ------------------------------------------ |
| 多轮对话     | 要引入对话状态管理 / 历史记忆，复杂度和 bug 面翻倍，超出 MVP 范围    |
| 并发 / 高可用 | 单机 6G 显存 + 本地服务，演示给面试官看够用就行                |
| 前端花活     | 一个命令行交互（或简单 Web 页面）足以演示链路；花时间做前端不如把评测数字做漂亮 |
| 流式输出     | Day9 接口已诚实拒绝（501）；流式对展示价值低                 |
| 全量微调     | QLoRA adapter 已经够"风格层"用，全量微调 6G 显存直接爆      |
| 联网搜索     | 知识库是离线私有资料，联网反而引入不可控                       |


一句话：**小而完整**——把"问 → 检索 → 拼模板 → 生成 → 带出处答案"一条链路走通，每个环节都有数字可讲。**面试官问"为什么不做多轮对话"，你答"MVP 先验证单轮问答的准确率，多轮是 Day14 之后的优化方向"——这叫"有取舍意识"，是加分项。**

### 2.2 数学视角：为什么分层（面试可讲）

把整条链路写成条件概率分解：

```
P(答案 | 问题) ≈ P_生成(答案 | 模板09( 检索(问题) ))
                     ↑           ↑        ↑
                  风格/能力层  答案组织层  检索层
```

- **检索层** = 条件于问题选"资料子集"：`P(资料子集 | 问题)`——先圈定"该看哪几段"；
- **答案组织层** = 把模型的支持集压到"只依据资料"：模板 09 的"资料里没有就答「资料中没有提到」"就是**硬约束**；
- **生成层** = 条件语言模型出词：`P(词序列 | 上下文)`——基础能力；
- **风格/能力层** = 把分布往"行业专家"方向收：LoRA 改的就是 `P(词 | 上下文)` 这个分布（Day12 已实证：格式、术语、口吻有肉眼差异）。

**分层的价值**：每层只干一件事，出问题时好定位——

- 答非所问 / 召回内容不对 → **检索层**（查 TOP_K、embedding、chunk 质量）；
- 格式乱 / 不按模板 → **答案组织层**（查模板 09）；
- 内容通顺但"不像行业专家" → **风格/能力层**（查 adapter）；
- 逻辑不通 / 编造 → **生成层**（查温度、模型大小）。

面试加分句："我的系统是四层解耦的，每层可以独立调优、独立评估——这正是 Day14 评测能定位到具体环节的原因。"

### A. 力扣 104. 二叉树的最大深度（简单 · 递归入门）⭐ 必做

**题目**：给定二叉树的根节点 `root`，返回其最大深度（根到最远叶子节点的节点数）。

**思路**：递归。一棵树的最大深度 = `1 + max(左子树深度, 右子树深度)`，空树深度为 0。**"递归三步走"**：① 终止条件（空节点返回 0）；② 本层干什么（取左右子树深度较大者 + 1）；③ 返回值（子树深度）。

**数学视角**：**递归 = 数学归纳法**——`depth(node) = 0`（空树，归纳基）→ `depth(node) = 1 + max(depth(left), depth(right))`（归纳步）。只要基和步都对，递归必然正确，不用脑补"递归到底怎么展开的"。

```python
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if not root:                # 终止条件：空树深度 0
            return 0
        return 1 + max(self.maxDepth(root.left),   # 左子树深度
                       self.maxDepth(root.right))  # 右子树深度
```

**复杂度**：每个节点访问一次，O(n) 时间；最坏退化成链时递归栈 O(n) 空间（平衡树为 O(log n)）。

### B. 力扣 226. 翻转二叉树（简单 · 递归）⭐ 必做

**题目**：翻转一棵二叉树（每个节点的左右子树互换）。

**思路**：递归。对每个节点：先翻转它的左右子树，再把左右孩子互换。终止条件同样是空节点。

**数学视角**：**递归 = 结构归纳**——翻转是"对整棵树做对称镜像"，可以逐节点定义：`invert(node)` = 先 `invert(left)`、`invert(right)`，然后 `left, right = right, left`。**先信任子问题已解决**（子树已翻转好），只处理当前节点的互换，问题就递归地解决了。Homebrew 作者当年面试被这道题挂掉，成了"递归经典梗题"。

```python
class Solution:
    def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        if not root:                     # 终止条件：空节点
            return None
        root.left, root.right = root.right, root.left   # 先交换当前节点的左右孩子
        self.invertTree(root.left)       # 再翻转左子树
        self.invertTree(root.right)      # 再翻转右子树
        return root
```

**复杂度**：O(n) 时间（每个节点访问一次）、O(n) 最坏空间（递归栈）。

**做完两题**：提交通过后存入 GitHub `leetcode` 仓库（`递归` 分类），题解注释写"数学视角"（归纳基 + 归纳步 / 结构归纳）。

### C. 统计八股：特征工程（10~15 分钟）

> 对应第三周计划 8/17："特征工程：缺失值处理、类别编码（one-hot/标签）、标准化 / 归一化、特征选择。"

- **缺失值处理**：删除（缺失比例高）、均值/中位数填充（数值型）、众数填充（类别型）、或建模预测填充。数学视角：缺失机制不同处理不同（MCAR 随机缺失可直接删，MAR/MNAR 要谨慎）；
- **类别编码**：**标签编码**（LabelEncoder，映射成 0/1/2…，**有序类别**适用，如学历）；**独热编码**（One-Hot，每个取值一列 0/1，**无序类别**适用，如行业）。数学视角：one-hot 把类别放进"单位向量空间"，两两距离相等（无大小关系）；标签编码会引入"3 > 2 > 1"的伪大小关系，无序类别别用；
- **标准化 vs 归一化**：**标准化（Z-score）** = `(x - μ) / σ`，变成均值为 0、方差为 1，**适合有异常值 / 算法假设正态（如 SVM、逻辑回归、PCA）**；**归一化（Min-Max）** = `(x - min) / (max - min)`，压到 [0,1]，**适合分布有界、无异常值**（如神经网络输入）。一句话：**看算法，不看数据**；
- **特征选择**：过滤式（方差、卡方、相关系数）、包裹式（递归消除）、嵌入式（L1 正则自动稀疏）。数学视角：特征选择 = **降维打击 + 防过拟合**——特征太多、样本太少时模型自由度爆炸（Day12 的过拟合话题的延续）。

> 面试加分句式："特征工程的总纲是'把数据变成模型假设的形式'——标准化是满足算法对量纲的假设，one-hot 是满足类别无序的假设，缺失值填充是满足'样本完整'的假设。我微调 LoRA 时也用到了特征工程的思路：把文本清洗成三字段统一格式，就是给 SFT 数据做'特征工程'。"

#### ① 缺失值处理

**1. 删除（缺失比例高）**

- **做法**：直接删除含有缺失值的样本（行）或删除缺失比例过高的特征（列）。
- **适用场景**：
  - 特征缺失比例超过 70%~80%，几乎没有信息量，删除特征比填充更稳妥；
  - 样本量非常大，缺失的样本只占少数，删除后不影响整体分布。
- **数学视角**：删除意味着放弃这部分样本所提供的"联合分布"信息。如果缺失是完全随机的，删除后数据仍然是无偏的；但如果缺失与某些变量相关，删除会导致样本选择偏差。

**2. 均值/中位数填充（数值型）**

- **做法**：用该特征的均值或中位数替代缺失值。
- **均值 vs 中位数**：
  - 均值对异常值敏感，若特征存在极端值，均值会被拉偏；
  - 中位数对异常值稳健，当特征分布偏态时优先用中位数。
- **适用场景**：缺失比例不高（例如 5%~15%），且特征大致服从对称分布时用均值；偏态或含异常值时用中位数。
- **数学视角**：均值/中位数填充本质上是把缺失值"推向数据中心"，这会低估数据的方差和协方差，导致后续模型对变量的离散程度估计失真，可能削弱特征的真实区分度。

**3. 众数填充（类别型）**

- **做法**：用该类别特征中出现频率最高的取值填充缺失值。
- **适用场景**：分类变量，比如"性别""地区"等，缺失量不大。
- **数学视角**：众数填充相当于用条件概率中概率最高的一类作为"最可能值"，但它没有考虑其他特征的影响，本质上是无条件最大后验估计的粗糙版本。如果其他特征能够预测该类别，这种填充方式会带来偏差。

**4. 建模预测填充**

- **做法**：把缺失值所在的列当作标签，用其他完整列作为特征，训练一个模型（如回归、KNN、随机森林）来预测缺失值。
- **适用场景**：特征间有较强相关性，缺失比例较高，且我们有足够的完整样本训练模型。
- **数学视角**：这相当于用条件期望 `E[X_missing | X_observed]`来估计缺失值。它利用特征之间的联合分布信息，比全局均值填充更精确。但要注意：如果缺失本身与未观测到的因素有关，预测填充可能引入偏差。

**5. 缺失机制（MCAR / MAR / MNAR）**

- **MCAR（完全随机缺失）**：缺失与任何变量无关，比如仪器随机故障。此时删除样本是安全的，不会引入偏差。
- **MAR（随机缺失）**：缺失与观测到的变量有关，比如高收入人群更不愿意透露收入。此时删除会带来偏差，因为剩下样本不再是随机的；需要结合其他变量填充。
- **MNAR（非随机缺失）**：缺失本身与缺失值有关，比如收入极高的人故意隐瞒。这种情况下任何填充都可能无法完全修复，需要专门的敏感性分析或模型假设。

#### ② 类别编码

**1. 标签编码（Label Encoding）**

- **做法**：把类别映射为整数，比如学历：小学=0，初中=1，高中=2，大学=3。
- **适用场景**：**有序类别**，也就是类别之间有天然的高低、大小、先后关系，比如学历、职称、满意度（差/中/好）。
- **数学视角**：标签编码给类别赋予了顺序，创建了一个"线性次序"。这在树模型（决策树、随机森林）中通常没问题，因为树只会做切分，不关心数值大小；但在线性模型、神经网络、距离计算中，标签编码会引入`3 > 2 > 1`这种伪大小关系。如果类别本来无序，模型会学到不存在的"量级差异"，从而降低效果。

**2. 独热编码（One-Hot Encoding）**

- **做法**：为每个类别生成一个二进制列，取值只能是0或1，例如"行业"有5个取值，就生成5列，每行对应其中一列为1。
- **适用场景**：**无序类别**，如行业、国家、颜色。
- **数学视角**：独热编码将每个类别映射到单位向量的顶点，比如红色=`[1,0,0]`，绿色=`[0,1,0]`，蓝色=`[0,0,1]`。任意两个类别的欧氏距离相等（都等于√2），点积为0，也就是互相正交。这样避免了虚假的次序，适合线性模型和基于距离的算法。缺点是维度爆炸：类别很多时会产生大量稀疏列，同时会造成多重共线性（可以用 `drop_first` 去掉一列）。

#### ③ 标准化 vs 归一化

**1. 标准化（Z-score）**

- **公式**：`z = (x - μ) / σ`
- **效果**：变换后数据均值为0，方差为1，且没有上下界，可以出现正负无穷的值。
- **适用场景**：
  - 特征含有异常值，因为标准化不强制固定区间，异常值虽然会被压缩，但不会全部挤在一起；
  - 算法假设特征服从高斯分布，比如线性回归、逻辑回归、SVM（RBF核）、PCA、LDA等。
- **数学视角**：标准化是对数据做"白化"的特例（去除均值、缩放方差），消除量纲和尺度差异。它保留了原始的离群比例，不受数据上下界约束，更适合大多数传统机器学习模型。

**2. 归一化（Min-Max）**

- **公式**：`x' = (x - min) / (max - min)`
- **效果**：将数据线性映射到 [0, 1] 区间（如果有负值也可映射到[-1,1]），但受最小值和最大值影响。
- **适用场景**：
  - 分布有界、无异常值；
  - 神经网络输入层通常用归一化，因为激活函数（如Sigmoid）对输入的范围敏感；
  - 需要固定量纲的场景，比如图像像素值归一化。
- **数学视角**：归一化是线性变换，完全由min和max决定，如果存在极端值，min/max会被拉偏，导致正常数据被压缩到很小的范围，损失区分度。它没有改变数据的分布形态，只是把尺度放缩到固定区间。

**3. 一句话总结：看算法，不看数据**

- **线性模型 / 距离模型 / 神经网络**：需要统一尺度，否则量纲大的特征会主导梯度或距离计算，此时标准化或归一化都可以，具体看数据是否有界、是否有异常值。
- **树模型（决策树、随机森林、XGBoost）**：缩放不影响分裂点的选择，做不做标准化/归一化都行。
- **PCA、聚类、KNN**：必须做，因为它们在计算协方差或距离，尺度不同会导致结果失真。

#### ④ 特征选择

**1. 过滤式（Filter）**

- **做法**：先对每个特征做单变量统计检验，打分排序，筛选得分高的特征。
  - 方差过滤：剔除方差接近0的特征（几乎无变化）；
  - 卡方检验：适用于分类问题中类别型特征与标签的相关性；
  - 相关系数：适用于数值型特征与数值型标签，看皮尔逊相关系数大小。
- **数学视角**：每个特征独立评估，速度快，但忽略了特征之间的交互作用。两个特征单独看都平庸，组合起来却可能很有预测力，过滤式方法抓不到这种组合效应。

**2. 包裹式（Wrapper）**

- **做法**：把特征选择包裹在模型训练过程中，通过反复添加/删除特征，观察模型性能指标（如AUC、MSE）来决定最优子集。典型算法是递归特征消除（RFE）。
- **数学视角**：包裹式策略是一种搜索问题——在特征子集空间中寻找使模型损失最小的组合。它能考虑特征之间的交互，但计算开销巨大，特征多时指数级复杂，容易过拟合。

**3. 嵌入式（Embedded）**

- **做法**：在模型训练过程中自动进行特征选择，最典型的是带L1正则项的线性模型（Lasso）。
- **L1正则化**：损失函数中加 `λ||w||_1`，即权重的绝对值之和。优化时，某些不重要的特征权重会被压缩到0，从而实现特征自动稀疏。
- **数学视角**：L1正则对应拉普拉斯先验，解在"菱形"约束面上容易落在坐标轴上，使不相关特征的系数变为0。它结合了过滤式的速度与包裹式的准确率，是实践中比较推荐的方法。树模型的特征重要性（如随机森林的重要性评分）也属于嵌入式思路。

**4. 数学本质：降维打击 + 防过拟合**

- **维度灾难**：特征维度增加时，数据在高维空间中变得稀疏，样本间距离趋同，模型自由度呈指数级增长——在样本量不变的情况下，模型复杂度上升，方差变大，导致过拟合（这也呼应了你Day12笔记中的过拟合话题）。
- **特征选择的作用**：降低自由度、减少噪声、提高信噪比，让模型泛化能力更强。同时，更少的特征也意味着更好的可解释性和更低的计算成本。

#### ⑤ 整体串起来

这些操作都是为了同一个目标：**在有限的样本下，把原始数据转换为更适合模型学习的结构，同时避免维度灾难和过拟合**。

- 缺失值处理解决"数据不完整"的问题，填充方法本质是在用已有的分布知识弥补缺失；
- 类别编码解决"数据不可计算"的问题，把非数值信息映射到合理的向量空间，避免错误的存在语义关系；
- 标准化/归一化解决"量纲不一致"的问题，让不同尺度的特征在同一尺度下参与计算；
- 特征选择解决"特征冗余或噪声"的问题，用数学手段剔除无关变量，降低模型复杂度。

在实际项目中，这四步通常的顺序是：先处理缺失值 → 再做编码 → 再缩放（如果需要） → 再做特征选择（或嵌入模型训练中）。每一步都需要你根据数据的分布、缺失机制、模型假设，灵活调整具体策略。
