## 一、评测设计（先定口径，再报数字）

把 RAG 的两种核心能力拆开量化，避免"一个总正确率糊过去"：

| 指标 | 口径 | 测什么 |
|---|---|---|
| 检索层命中率 | 资料内 10 题中，`source_chunk`（标准答案所在段落）被 Top-K 召回的占比 | 该找的段落有没有找到（= 信息检索的 Recall@K） |
| 生成层正确率 | 资料内 10 题中，答案命中期望关键词的占比 | 找到段落之后，答没答对 |
| 防幻觉正确率 | 资料外 10 题中，如实答「资料中没有提到」的占比 | 没有答案时能不能忍住不编（RAG 核心卖点） |
| 防幻觉 F1 | 把"该不该拒答"当二分类，算精确率 / 召回率 / F1 | 拒答准不准、漏放多少幻觉 |

**判分方式**：规则判分（关键词子串命中 + 拒答词表），可复现、零成本；自动判分后逐题人工复核，误判经 `MANUAL_FIXES` 修正（Q9 关键词碰巧命中改判错、Q18 拒答词漏网改判错），保证进简历的数字诚实。

## 二、评测结果（首版基线）

| 指标 | 数值 |
|---|---|
| 检索层命中率 | **2/10 = 20%** |
| 生成层正确率（资料内） | **2/10 = 20%** |
| 防幻觉正确率（资料外） | **6/10 = 60%** |
| 总正确率（20 题） | **8/20 = 40%** |
| 防幻觉 F1 | **0.667**（精确率 0.75 / 召回率 0.60） |

**防幻觉 2×2 混淆矩阵**（把 20 题当二分类：真实"该不该拒答" vs 模型"拒不拒答"）：

| | 真实：资料外（应拒答） | 真实：资料内（应作答） |
|---|---|---|
| 模型拒答 | TP = 6（真防住） | FP = 2（该答没答） |
| 模型没拒答 | FN = 4（幻觉漏网） | TN = 8（正常作答） |

## 三、样例问答

> 以下为 Day15 双链路冒烟测试的实测文本（跑 `第三周/day15/ask.py`，两条链路同一组 3 条题，检索 Top-K 完全一致、仅生成层不同）。有截图的话贴终端截图，没有就用文本即可。答案原文照抄 `冒烟日志_lora.txt` / `冒烟日志_original.txt`，未做修改。

### 3.1 资料内问题：论文的实验在哪个数据集上进行？

- **微调模型答案**（本次未点名数据集，如实记录）：
  ```
  GMR consistently outperform existing open-source methods [3] in both tracking 性能和源运动态一致性，实现感知真实性和政策成功率接近闭源基线。
  ```
- **原模型答案**（命中 LAFAN1）：
  ```
  实验在 LAFAN1 数据集上的多样本子集上进行 [3]。 [资料§3]
  ```

> 备注（诚实声明）：3.1 这一题上，本次微调链路单次生成未点名 LAFAN1、原模型答对——两路检索到的 Top-K 完全相同（`[103, 4, 25, 3]`，均含答案段落 §3），差异纯在生成层。而在 Day14 的 20 题评测中，微调模型在本题（Q5）**成功答出 LAFAN1**（评测表 Q5 ✅）。两次一对照，恰好实证了评测局限第 4 条"单次生成有随机性"：temperature=0.2 已压熵但未消除，单条问答不构成结论，要看多题统计（评测表口径）。

### 3.2 资料外/反事实问题：华为的人形机器人是否采用了 GMR 方法？

- **微调模型答案**（如实拒答）：
  ```
  资料中没有提及。
  ```
- **原模型答案**（如实拒答，且标了出处）：
  ```
  资料中没有提到 [资料§36]。
  ```

> 备注：两条链路都正确拒答，未编造"是/否"——**防幻觉能力在双链路下都成立**，这是 RAG 相对裸大模型的核心卖点，面试可用这组样例现场演示。

### 3.3 两条链路风格差异

| 维度 | 原模型表现 | 微调模型表现 |
|---|---|---|
| 答案风格 | 展开式：Q1 除结论还补"用户很难区分 GMR 和 Unitree"等解释；整体更长、更像百科讲解 | 收束式：Q1 直接给结论 + 简评"更为忠实参考运动且成功率高"；整体更短、更"结论式" |
| 出处标注 | 句内多处 `[资料§N]`，拒答句也带出处（`[资料§36]`），最贴模板 09 | 句尾标纯数字 `[18]` / `[3]`（无 `资料§` 前缀），出处较少 |

Day12/13 在接口层观察到的差异（微调更凝练专业、原模型更长更口语）在**完整 RAG 链路下依旧成立**。同时如实记录两点：① 微调模型出处标注偏简，格式一致性可列入后续观察；② 单题上原模型也可能答得更好（见 3.1），**"风格变好 ≠ 事实一定答对"**——风格差异与事实能力需分开评估，后者以 20 题评测统计为准。

> 两条链路完整问答文本见 `双链路冒烟测试记录.md`。

## 四、结论与错误归因（分层定位）

> 评测的价值不是报一个数，而是**把低分归到具体层**（Day13 四层架构的直接回报）。

1. **主瓶颈 = 检索层召回**：8/10 的资料内题连答案所在段落都没被 Top-K 召回（命中率仅 20%）——生成层"巧妇难为无米之炊"。这是 Day15 之后 P1 调优的第一目标：`TOP_K` 4→8、`chunk_size` 500 vs 800、Embedding 模型对比。
2. **生成层偶发幻觉**：防幻觉 FN=4，典型如 Q18（编造一串引用统计数字后补一句拒答词）——说明规则判分看词不看内容，也是真实缺陷；Q11 在 temperature=0.2 下仍会采样出"从资料拼句子作答"，单次生成有随机性。
3. **过拒答存在但不多**：FP=2（资料里有答案却答"没有提到"），如 Q7——模板 09 的拒答指令对部分 in 题过强，后续可在模板与检索上平衡。
4. **微调链路 vs 原模型链路**：功能上两条链路都通；风格差异（微调更凝练）在接口层已验证（day13 冒烟记录），完整 RAG 链路下的定量对比列为 P2 第二版评测。

## 五、局限（诚实声明，主动讲）

1. **样本量小**：n=20，正确率点估计的 95% 置信区间宽度约 ±0.22，结论看量级、不抠小数点；
2. **规则判分是宽松近似**：关键词/拒答词子串匹配可能误报，已用人工复核 + `MANUAL_FIXES` 兜底；
3. **评测分布 ≠ 真实分布**：真实用户问题大多属于资料内，评测集"两类各半"是为同时测两个方向——真实场景总正确率预期高于 40% 这个口径；
4. **单次生成有随机性**：temperature=0.2 已压熵，严谨做法是每题多次取多数（列为 P2 可选）。
