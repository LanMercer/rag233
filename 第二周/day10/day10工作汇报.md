## 三、第十天工作成果

### 3.1 主线任务（3~4h）

| 任务 | 完成情况 | 说明 |
| ---------------------- | ---- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 概念学习（RAG / Embedding / 向量数据库 / 余弦相似度 / Top-K / 切块） | ✅ | 每个新名词都按"新名词必带简介"配了大白话解释 + 类比。**RAG**（Retrieval-Augmented Generation，检索增强生成）= 先从资料库"查答案"再让模型"组织答案"，专治大模型不知道的私有/新资料；**Embedding**（嵌入/文本向量化）= 把文本变成一串数字，语义近的向量距离近；**Chroma** = 开源向量数据库，存"向量+原文"按相似度检索；**余弦相似度** = 两向量夹角余弦 `cos(a,b)=(a·b)/(|a||b|)`；**Top-K** = 取相似度最高的前 K 个片段；**切块** = 把长文档按中文标点切小块。并讲清"为什么 RAG 不用重新训练"（成本 / 更新速度 / 可解释性三点对比） |
| 数学视角贯通 ⭐ | ✅ | **检索 = 高维向量空间最近邻问题**；**"打分 → 取 Top-K → 融合"与第一周注意力三步走同构**（Attention 在模型内部做软性检索，RAG 在模型外部做硬性筛选）——这是把两周知识打通的连接点，面试可直接复述 |
| 环境准备 + 依赖安装 | ✅ | 装了 6 组新依赖（pypdf / chromadb / langchain 全家桶 / sentence-transformers 等）；**踩了 langchain 1.x 的大版本坑**（`RecursiveCharacterTextSplitter` 移到了独立包 `langchain-text-splitters`），已修复教程与代码（详见踩坑表 #1） |

## 四、踩坑与解决（过程真实记录）

| # | 问题 | 解决办法 |
| --- | -------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 1 | **langchain 1.x 大版本坑**：`from langchain.text_splitter import RecursiveCharacterTextSplitter` 报 `ModuleNotFoundError` | langchain 1.x 把切块拆到了独立包 `langchain-text-splitters`。改用 `from langchain_text_splitters import ...`；同步更新教程依赖清单与避坑表（第 0 步版本坑位写了 4 条实测踩过的坑） |
| 2 | **bge 模型下载失败**：连 hf-mirror 报 `OSError: We couldn't connect to 'https://hf-mirror.com'` | 本机网络连不上 HuggingFace 镜像。改用 **ModelScope**（`snapshot_download('AI-ModelScope/bge-small-zh-v1.5')`）下载到 `download\bge-small-zh-v1.5`（约 96MB），三个脚本 `EMBED_MODEL` 指向本地路径加载，免联网 |
| 3 | **重跑建库数据重复**：检索结果里同一个 chunk 出现两次 | `Chroma.from_documents` 默认往同一个 collection **追加**而非覆盖。给 `build_index.py` 加"建库前自动清空旧库"逻辑（`shutil.rmtree`），并加进教程 3.2 自测题 #4 |
| 4 | **终端打印 `✅` 崩**：`UnicodeEncodeError: 'gbk' codec can't encode character '\u2705'` | Windows 控制台默认 GBK 打不出 emoji。三个脚本统一加 `sys.stdout.reconfigure(encoding="utf-8", errors="replace")` 加固，`✅` 改为纯文字 `[完成]`；教程避坑表同步记录 |
| 5 | **`langchain-community` 废弃警告** | 官方已标记 sunset（停更），import 打 DeprecationWarning——**无害**，忽略即可；官方建议迁 `langchain-pypdf`（镜像源暂无该包，用 community 版可用） |
| 6 | **`ask.py` 曾长时间卡住** | 排查发现 Day9 服务中途停了，请求发不出去就挂住。此后先 `curl.exe http://127.0.0.1:8000/health` 确认服务活着再跑；教程避坑表新增"模型生成很久没返回"条目 |
| 7 | **验收第 5 步教程太简略** | 按反馈把第 5 步扩成手把手操作版（5.0~5.5），每步标明改哪个文件哪一行、预期看什么输出 |
| 8 | **牛客真题不知道去哪找** | 查证后补充 3 种入口：直达链接 `nowcoder.com/exam/company?tagIds=811`、导航路径（题库 → 公司真题 → 国央企）、考情帖（银行笔试话题区 + 备考经验帖） |
