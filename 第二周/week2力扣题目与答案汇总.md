> 数据结构小抄（周内新增名词，初次出现即解释）：
>
> - **链表（Linked List）** = 一串节点手拉手：每个节点存一个"值" + 一个"指向下一个节点的指针"（`node.next`）。和数组不同，它不能按下标 O(1) 直达，只能从头挨个走（`O(n)` 找、O(1) 插入/删除）。链表的"指针操作"（改 next）是刷题核心，改错方向就断链。
> - **快慢指针（Fast & Slow Pointers）** = 两个指针同时从头部出发，一个每次走 1 步、一个每次走 2 步。速度差让它们能在"环"里相遇、在"中间"碰头——把链表问题变成"追及问题"（数学视角）。
> - **蓄水池抽样（Reservoir Sampling）** = 不知道数据总量 N 时，要等概率抽 1 个：遍历时以概率 `1/i` 替换当前"幸运儿"。数学上保证每个元素最终被抽中的概率都是 `1/N`（裂项相消）。

## 专题一：字符串（String）

### 1. 344. 反转字符串 —— 简单 ✅（8/8 · Day6 完成）

**考点**：双指针 / 原地修改

**思路**：两个指针 `i` 从头部、`j` 从尾部，交换 `s[i]` 与 `s[j]` 后相向移动，直到相遇。题目要求原地修改（`O(1)` 额外空间），不能新建数组。

**代码**：

```python
def reverseString(s):
    i, j = 0, len(s) - 1
    while i < j:
        s[i], s[j] = s[j], s[i]   # 头尾互换
        i += 1
        j -= 1
```

**复杂度**：时间 O(n)，空间 O(1)。**数学视角**：这就是"对折交换"——每次交换位置 `i` 和 `len-1-i` 一对对称点，是"镜像/对称变换"的最简实现。

### 2. 125. 验证回文串 —— 简单 ✅（8/8 · Day6 完成）

**考点**：双指针 / 字符处理（高频）

**思路**：先跳过非字母数字字符、统一忽略大小写，再用头尾双指针判断对称：`i`、`j` 各自向内跳过无效字符，比较 `s[i].lower()` 与 `s[j].lower()`，一旦不等就不是回文。

**代码**：

```python
def isPalindrome(s):
    i, j = 0, len(s) - 1
    while i < j:
        while i < j and not s[i].isalnum():   # 跳过非字母数字
            i += 1
        while i < j and not s[j].isalnum():
            j -= 1
        if s[i].lower() != s[j].lower():
            return False
        i += 1
        j -= 1
    return True
```

**复杂度**：时间 O(n)，空间 O(1)。**数学视角**：回文 = 对称性——字符串关于中点对称，和"矩阵转置对称""偶函数"是同一个思想（`f(x)=f(-x)`）。

### 3. 14. 最长公共前缀 —— 简单 ✅（8/9 · Day7 完成）

**考点**：纵向比较（逐个字符串逐列比对）

**思路**：把第一个字符串当基准，逐列比较所有字符串同一位置的字符：都相同就继续，遇到不一致或某个字符串到头就返回已累积的前缀。

**代码**：

```python
def longestCommonPrefix(strs):
    if not strs:
        return ""
    for col in range(len(strs[0])):            # 逐列（第 col 个字符）
        ch = strs[0][col]
        for s in strs[1:]:
            if col >= len(s) or s[col] != ch:  # 某个串到头了或不一样
                return strs[0][:col]           # 返回已确认的前缀
    return strs[0]
```

**复杂度**：时间 O(n×m)（n 个串、平均长度 m），空间 O(1)。**数学视角**：公共前缀 = 多个集合的"交集"的最前段——逐列做"一致性检验"，遇到不一致就停（类比多个分布的前几个时刻都相等，再多就分化了）。

### 4. 415. 字符串相加 —— 简单 ✅（8/9 · Day7 完成）

**考点**：模拟进位（数学思维）

**思路**：两个数字字符串从低位（末尾）向高位逐位相加，维护 `carry`（进位）。每次 `a + b + carry`，个位 `%10` 进结果、十位 `//10` 当新进位；循环结束后若还有进位要补一位。不能直接 `int(num1) + int(num2)`（会溢出或超时）。

**代码**：

```python
def addStrings(num1, num2):
    i, j = len(num1) - 1, len(num2) - 1
    carry = 0
    res = []
    while i >= 0 or j >= 0 or carry:
        a = int(num1[i]) if i >= 0 else 0
        b = int(num2[j]) if j >= 0 else 0
        total = a + b + carry
        res.append(str(total % 10))   # 当前位
        carry = total // 10           # 进位
        i -= 1
        j -= 1
    return ''.join(reversed(res))
```

**复杂度**：时间 O(max(n, m))，空间 O(max(n, m))。**数学视角**：这就是小学列竖式加法——从低位到高位逐位相加，`carry`（进位）像"余数/溢出"一样向高位传递，是"模 10 运算 + 整除"的模拟。

## 专题二：链表（Linked List）

### 5. 206. 反转链表 —— 简单 ✅（8/10 · Day8 完成）｜ 最高频必做

**考点**：迭代 / 递归

**思路**：迭代法：用 `prev`（前一个节点）、`cur`（当前节点）两个指针，每步先把 `cur.next` 存到 `nxt`，再把 `cur.next` 指向 `prev`，然后 `prev`、`cur` 各进一步。遍历完 `cur` 为空时，`prev` 就是新头。递归法：先反转子链表，再把当前节点的 next 的 next 指向自己、自己的 next 置空。

**代码**：

```python
def reverseList(head):
    prev = None
    cur = head
    while cur:
        nxt = cur.next        # 先存住后继，防止断链
        cur.next = prev       # 把指针掉头
        prev = cur            # 前移
        cur = nxt
    return prev               # 新头
```

**复杂度**：时间 O(n)，空间 O(1)（迭代）。**数学视角**：链表反转 = 原地修改"指针方向"，相当于把访问顺序倒过来（像矩阵转置改变行列遍历顺序）；递归版 = 递推公式 `f(node) = f(node.next) 再接上 node`。

### 6. 21. 合并两个有序链表 —— 简单 ✅（8/10 · Day8 完成）｜ 必做

**考点**：归并思想（两路归并）

**思路**：用一个 `dummy` 哨兵节点当新链表头（避免处理头节点为空的特例）。双指针 `l1`、`l2` 分别指向两个链表头，谁的值小就把谁接到 `tail` 后面并前进一步；一方走完，把另一方剩下的整串接上。

**代码**：

```python
def mergeTwoLists(l1, l2):
    dummy = ListNode(0)        # 哨兵节点，方便返回头
    tail = dummy
    while l1 and l2:
        if l1.val < l2.val:
            tail.next = l1
            l1 = l1.next
        else:
            tail.next = l2
            l2 = l2.next
        tail = tail.next
    tail.next = l1 if l1 else l2   # 接上剩余部分
    return dummy.next
```

**复杂度**：时间 O(n+m)，空间 O(1)。**数学视角**：这就是归并排序的"合并（merge）"子过程——两个有序序列合成一个有序序列，是分治思想的基石。第一周数组版（88 题）是同一套逻辑，链表版天然好写。

### 7. 876. 链表的中间结点 —— 简单 ✅（8/11 · Day9 完成）

**考点**：快慢指针

**思路**：`slow` 每次走 1 步、`fast` 每次走 2 步，同时从头部出发。`fast` 到末尾（或 `fast.next` 为空）时，`slow` 正好在中间。偶数个节点时注意题目要求"取后一个中间点"。

**代码**：

```python
def middleNode(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next        # 每次走 1 步
        fast = fast.next.next   # 每次走 2 步
    return slow                 # fast 到终点时 slow 在中间
```

**复杂度**：时间 O(n)，空间 O(1)。**数学视角**：这就是追及/路程问题——速度比 1:2，同时同起点出发，时间相同时路程比 1:2：慢指针走的路程 = 快指针的一半 = 链表总长的一半。

### 8. 141. 环形链表 —— 简单 ✅（8/11 · Day9 完成）｜ 高频

**考点**：快慢指针（Floyd 判圈）

**思路**：`slow` 走 1 步、`fast` 走 2 步。若链表有环，两者终会在环里相遇；若无环，`fast` 会先走到 `null`。相遇即返回 True。

**代码**：

```python
def hasCycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast:        # 环内相遇
            return True
    return False
```

**复杂度**：时间 O(n)，空间 O(1)。**数学视角**：追及问题的"相对速度"思想——进环后 `fast` 相对 `slow` 每步只靠近 `2-1=1` 格，环长 L 最多 L 步必追上；而"最多走 O(n) 步"由抽屉原理保证（节点一共就 n 个）。进阶：142 环形链表 II 求环入口，需 `2(a+b)=a+b+nL` 的数学推导（不在本周必做范围）。

### 9. 382. 链表随机节点 —— 中等 ✅（8/12 · Day10 完成）｜ **概率加成收官题，务必拿下**

**考点**：蓄水池抽样（Reservoir Sampling）

**思路**：题目要求等概率返回链表任一节点的值，但链表长度未知、内存装不下（无法先数 N 再随机索引）。**蓄水池抽样**：遍历链表，维护一个"幸运儿" `result`，第 i 个节点以概率 `1/i` 替换它。数学上可证每个节点最终胜出的概率都是 `1/n`。

**代码**：

```python
import random

class Solution:
    def __init__(self, head):
        self.head = head

    def getRandom(self):
        result = None
        node = self.head
        i = 0
        while node:
            i += 1
            if random.randint(1, i) == 1:   # 以 1/i 的概率替换"幸运儿"
                result = node.val
            node = node.next
        return result
```

**复杂度**：时间 O(n)，空间 O(1)。**数学视角（面试推导，重点）**：第 k 个节点最终胜出 = 被第 k 次选中 × 之后 k+1…n 次都"没被替换"：

```
P(第k个胜出) = (1/k) × (k/(k+1)) × ((k+1)/(k+2)) × … × ((n-1)/n)
             = 1/n      ← 相邻项分子分母约掉（裂项相消）
```

每个节点都是 `1/n`，等概率成立。这也是总纲点名的"数学概率加成题"——蓄水池抽样/洗牌算法/生日问题这类概率题，既是考点，也是面试讲"数学优势"的素材。

### 10. 160. 相交链表 —— 简单 ✅（8/11 计划 · 周内补做完成）｜ **数学思维加分题**

**考点**：双指针 / 路程差

**思路**：两条链表可能长短不一，但相交点之后的部分完全相同。双指针 `a` 从链表 A 头部出发、`b` 从链表 B 头部出发，同步各走 1 步；**谁走到头就跳到对方链表头部继续走**。两指针走过的总路程都是 `A链长 + B链长`：

- 若相交：路程差被"互相换头"抹平，两指针恰好同时到达交点；
- 若不相交：两指针同时走到 `null`，返回 None。

等价于"把两条链表按尾部对齐再从头比较"——共同后缀越长，对齐后越早相遇。

**代码**：

```python
def getIntersectionNode(headA, headB):
    a, b = headA, headB
    while a is not b:          # 不相交则最终同时为 None
        a = a.next if a else headB   # 走到头换到对方链表
        b = b.next if b else headA
    return a
```

**复杂度**：时间 O(n+m)，空间 O(1)。**数学视角（面试重点）**：这是"路程相等 → 相遇"的追及思想——设 A 链公共前缀长 a、B 链公共前缀长 b、公共部分长 c，`a` 指针全程走 `a + c + b`，`b` 指针全程走 `b + c + a`，两者总路程**恒相等** `a+b+c`。无论长短如何，交换起点后它们必然同时到达交点（或同时到达 null）。同题还有哈希集合解法（先存 A 全链再遍历 B 查交集，O(n) 空间），双指针版是"用路程差消除长度差"的最优解。
